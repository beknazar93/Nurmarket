# NurMarket Поддержка — программа сотрудника техподдержки

Подключение к кассам клиентов через ретранслятор `NurRemoteSupport/Server` (протокол — `../PROTOCOL.md`, v1.1).
Без согласия кассира («Разрешить» на кассе) подключиться нельзя.

## Что умеет

- **Ждут помощи** — кассы, где кассир нажал «Получить код для поддержки»: компания, компьютер, кассир, «что случилось» со слов кассира, сколько ждёт. Обновляется каждые 3 с, о новой кассе — сигнал и сообщение. Подключение — кассир диктует только PIN.
- **Подключиться по коду** — код (9 цифр) и PIN, если кассир диктует оба.
- **Окно сеанса:**
  - экран кассы: вписать / 1:1 / во весь экран, курсор кассы;
  - мышь и клавиатура, «Только просмотр»;
  - качество картинки;
  - меню комбинаций (Ctrl+Shift+Esc, Alt+Tab, Win+R, Win+D, Alt+F4…);
  - кадры в секунду и скорость.
- **Вкладки сеанса:**
  - «Чат» — с кассиром, есть готовые фразы;
  - «Касса» — сведения о кассе и компьютере;
  - «Диагностика» — связь с NurCRM, время, чеки без связи, принтер, диск, память, ошибки в журнале;
  - «Журнал» — 300 / 2000 строк, все журналы zip;
  - «Файлы» — отправить файл кассиру, до 100 МБ;
  - «Буфер» — положить текст в буфер обмена кассы, напечатать на кассе, взять её буфер;
  - «Заметки» — история обращений этой кассы и новая заметка.
- **Журнал сеансов** — кто, к какой кассе, сколько длилось, чем кончилось; нажатие на строку открывает историю кассы.
- **Заметки и обращения** — заметки всех операторов, с поиском.
- Пять языков: ru, ky, en, tr, uz.

## Запуск

1. На сервере поддержки завести сотрудника: `dotnet Server.dll add-operator <логин> "<Имя>"` (пароль вводится со stdin).
2. Отдать сотруднику `NurMarketSupport.exe`. Это один файл, .NET не нужен. Собирается так:
   `dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o bin/publish`
3. При первом входе указать адрес сервера поддержки (по умолчанию `https://support.nurcrm.kg`), логин и пароль. Адрес и логин запоминаются; пароль и токен — нет.

Полученные с кассы файлы (журналы zip) сохраняются в «Загрузки\NurMarketSupport».

## Проверка без помех людям на ПК

`powershell -ExecutionPolicy Bypass -File tools\qa\support_qa.ps1 -OutDir <папка>` запускает:
- свой сервер на 127.0.0.1;
- поддельную кассу FakeHost;
- программу оператора за краем экрана.

Снимки делаются по hwnd.

С `-RealHost` вместо FakeHost запускается стенд с настоящим кодом кассы (`Tools/HostHarness`). Он передаёт настоящий экран ПК, поэтому снимки обрезаются до панели инструментов.
