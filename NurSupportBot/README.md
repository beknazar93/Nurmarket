# NurSupportBot — Telegram-бот обучения и поддержки клиентов NurCRM

Один общий бот NBS Holding для всех клиентов. Работает на сервере 24/7 и не зависит от касс.
Запуск на сервере — `deploy/README.md`.

## Что умеет

- **Обучение:** меню «раздел → операция → видео + пошаговый текст», кнопки «✅ Помогло / ❌ Мне не помогло».
- **Поиск:** клиент пишет вопрос своими словами — бот предлагает подходящие инструкции (по названию, ключевым словам и тексту).
- **Оператор:** «Связаться с оператором» → клиент описывает проблему, прикладывает скриншоты/видео → обращение уходит
  в группу поддержки с именем, компанией, тарифом, разделом и отметкой «не помогло». Оператор отвечает ответом
  на сообщение — клиент получает ответ в боте и может ответить обратно; закрытие — кнопкой или `/close`.
- **Вход через NurCRM:** логин и пароль NurCRM → бот узнаёт компанию, тариф, сферу и роль. Пароль не хранится,
  сообщение с паролем удаляется; refresh-токен хранится зашифрованным (AES-GCM, ключ `data/token.key`).
- **Финансовый отчёт:** сегодня / вчера / неделя (с понедельника) / месяц (с 1-го) — выручка, чеки, средний чек,
  наличные, безнал, возвраты, прибыль и маржа. Данные с сервера NurCRM (`analytics/market?tab=sales`) — те же, что на сайте.
- **Админка в Telegram** (`/admin`, только `AdminIds`): разделы и инструкции любой вложенности, текст, видео/фото
  (просто отправить ролик боту), ссылка на видео, ключевые слова, порядок, архив, удаление; контакты поддержки;
  открытые обращения; статистика; выгрузка базы `/export` и загрузка JSON с подписью `/import`.
- **Статистика за 30 дней:** пользователи, просмотры, «помогло / не помогло», обращения, доля решённых без
  оператора, популярные разделы и инструкции, что ищут и что не находят.

## Устройство

| Файл | Что внутри |
|---|---|
| `Program.cs` | запуск, первичная загрузка `seed/kb.json`, служебные режимы `--import`, `--export`, `--search`, `--crm-test` |
| `Telegram/TgClient.cs` | тонкий клиент Bot API (long polling, без сторонних библиотек) |
| `Data/Db.cs` | SQLite: инструкции, пользователи, состояния диалога, обращения, события, настройки |
| `Bot/SupportBot*.cs` | меню и инструкции, обращения, отчёт, админка |
| `Services/` | NurCRM (вход, отчёт), шифрование токена, поиск, импорт/экспорт базы |
| `seed/kb.json` | черновик базы инструкций, грузится при первом запуске |

## Локальный запуск

```
cp appsettings.example.json appsettings.json   # вписать BotToken и AdminIds
dotnet run -c Release
```

Проверка поиска без Telegram: `dotnet run -c Release -- --search "как сделать возврат" "где остатки"`.
