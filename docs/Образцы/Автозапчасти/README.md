### 1.1 Структура и примеры (без персональных данных)

**avtoskazka-price-foreign.xlsx / -oil / -tools** — лист «Лист 1». Строка 1 — дата («19 ноября 2026»), строка 2 — заголовки, дальше строки-группы (только название, без цены) вперемешку с товарами.
Колонки: `Наименование; Код товара; Производство; Артикул; Цена`.
```
Амортизаторы                                        (строка-группа, остальные ячейки пустые)
Амортизатор газовый передний левый Kia  PJB049A | i05115 |        | PJB049A | 5240
Амортизатор газовый передний лев. Ford DG11057  | i14337 |        | DG11057 | 5700
Герметик шин 450 мл., ABRO MASTERS (oil)        | 00571  | ABRO   |         | 500
```
Особенности: бренд зашит в название (иногда есть в «Производство»); остатка нет; применимость («Kia», «VW») и объём («450 мл», «1л») только в тексте названия; артикул у части товаров пуст; цена в рублях целая.

**interrus-shiny-optom.xlsx** — лист «Шины оптом». Строки 1–3 — шапка с условиями (минимальный заказ, телефоны), строка 5 — заголовки.
Колонки: `Бренд; Модель; Типоразмер; Сезон; Индексы; Особенности; Класс; Цена, руб.; Наличие; Артикул; Код производителя`.
```
Bridgestone | Alenza 001 | 255/55 R19 | лето | 107 W    |  | легковая | 22230.0 | 8–20      | 244524 | 10444
Bridgestone | Alenza 001 | 255/55 R19 | лето | 111 H XL |  | легковая | 24020.0 | менее 8   | 255511 | 10428
```
Особенности: «Наличие» — диапазон текстом («20–50», «менее 8»), не число; названия товара нет — его надо собрать из «Бренд + Модель + Типоразмер + Индексы + Сезон»; десятичная цена с «.0».

**autobody-forward-price-csv.zip → forward_price1.csv** — CSV, Windows-1251, разделитель «;», CRLF, после заголовка в последней колонке стоит дата-время выгрузки.
Колонки: `Код1с; Артикул; OEM; Группы\; ГОД/Вольтаж; Наименование; Цена Руб; ПЕЧАТНИКИ(Остаток); САНКТ-ПЕТЕРБУРГ(Остаток); ОМСК(Остаток); КАПОТНЯ(Остаток); …(Ожидаем) ×4; Производитель; НомерПроизводителя; ГруппаСкидки; Сертификат; ДатаСертификата; СрокДействияСертификата; СсылкаНаСертификат; ТНВЭД`.
```
33891 | AI0Q508-220 | 8R0807061C | ЕВРОПА\AUDI\AUDI Q5 (08-17) | 08- | AUDI Q5 '08- СПОЙЛЕР БАМПЕРА ПЕРЕДН (ТАЙВАНЬ) | 6370 | 0 | 0 | 0 | 0 | … | API | AU3700130-1000 | 1 | ЕАЭС RU С-DE.НА96.В.03900/24 | …
38703 | HNAVA14-071-L | 922013X230 | КОРЕЯ\HYUNDAI\HYUNDAI ELANTRA/AVANTE (10-) | 14- | AVANTE '14- ФАРА ПРОТИВОТУМ ЛЕВ С DRL (DEPO) | 2272 | 0 | 0 | 0 | 0 | … | DEPO | 221-2050L-UEN | 1 | ЕАЭС KG417/052.DE.02.05443 | …
```
Особенности: это лучший образец «OEM + применимость»: OEM (иногда несколько через «+»), путь «страна\марка\модель (годы)» — готовое поле «Подходит к»; остатки по 4 складам и «ожидаем»; сертификаты ЕАЭС (есть KG-сертификат); 18+ колонок. Код ЕАЭС/ТНВЭД пригодится для маркировки.

**avtogarant-offline.xls** — лист `Sheet1`, 9 колонок, строки 1–8 — шапка (реквизиты, «форма оффлайн-заказа», поля «Клиент/Дата/Транспортная»), строка 9 — заголовки, дальше строки-группы (номер + название группы) и товары.

Особенности: две цены (нал/безнал), пустая колонка «Заказ» (клиент вписывает количество), номера «1.0» как числа, остатка нет. Формат .xls (BIFF, CP1251).

## 2. Как это загрузила бы наша «Массовая загрузка» (по коду, вживую не гоняли)

Заголовок строкой ищется автоматически (`DetectHeaderRow`) и выбирается вручную; сопоставление запоминается по «подписи» заголовков. Профили источников: 1С, МойСклад, Poster, Loyverse, Paloma365, Umag, Rosta — профиля «Прайс поставщика» нет (в ТЗ автозапчастей он помечен v2).

## 3. Тестовый набор `demo-autoparts-catalog.csv` (магазин «Автозапчасти», вымышленный)

- 170 позиций, UTF-8 с BOM (чтобы Excel открывал русский текст), разделитель «;», CRLF, поля с «;» внутри («Подходит к») в кавычках — это сразу проверка разбора кавычек.
- Колонки (15): Название; Бренд; Каталожный номер; OEM; Кросс-номера (через запятую); Подходит к; Состояние (Оригинал / OES / Аналог / Б/У); Страна; Ячейка; Закупка; Розница; Цена СТО; Остаток; Гарантия (дней); Штрихкод.
- Состав: масляные (12), воздушные (10), салонные (8), топливные (8) фильтры; колодки передние (8) и задние (6); тормозные диски (6); свечи (10); комплекты ГРМ и ремни (8) и поликлиновые (4); амортизаторы (10); подвеска и рулевое (10); подшипники ступиц (5); масла 5W-30 / 5W-40 / 10W-40 / 0W-20 по 1/4/5 л, ATF, трансмиссионные (21); антифриз и тормозная жидкость (8); лампы (8); щётки (6); аккумуляторы (6); шины (8); Б/У «с разборки» (8: донор, вымышленный VIN, фото, пробег — в колонке «Подходит к», для них Бренд = «Без бренда», номер `BU-nnn`).
- Бренды: Bosch, Mann-Filter, Mahle, Knecht, Filtron, Hengst, Sakura, Denso, NGK, Champion, TRW, Ate, Ferodo, Textar, Brembo, Gates, Contitech, SKF, Dayco, Kayaba, Sachs, Monroe, Bilstein, Lemförder, FAG, INA, Castrol, Mobil, Shell, Total, Liqui Moly, Osram, Philips, Valeo, Varta, Exide, Michelin, Bridgestone, Nokian, Hankook, Kumho и др.
- Цены в сомах, закупка < Цена СТО < Розница; остатки 0–24 (у ~10 % позиций 0 — для проверки «нет в наличии»); ячейки A-01-1…H-18-5 по зонам (A фильтры, B тормоза, C двигатель, D подвеска, E жидкости, F свет, G аккумуляторы, H шины, Y разборка); штрихкод у 116 позиций из 170 (54 без штрихкода), формат EAN-13 с префиксом 29 — это внутренний диапазон GS1, он не совпадает с настоящими товарами.
- Честная оговорка: каталожные номера и кроссы правдоподобные, но применимость по авто и соответствие номеров вымышлены/не сверены с каталогами (TecDoc и т. п.). Использовать только для тестов поиска, импорта и вёрстки, не для продажи и не как справочник.

Как загрузить в нынешнюю «Массовую загрузку»:
- Название → Название; Розница → Продажа; Закупка → Закупка; Остаток → Количество; Бренд → Бренд; Штрихкод → Штрихкод.
- «Каталожный номер» — в списке синонимов поля «Артикул» (`артикул, art, код, кодтовара, article, sku…`) слова «каталожный номер» нет: в большинстве случаев сопоставление придётся задать вручную (после этого касса запомнит его); либо переименовать колонку в «Артикул». Лучше добавить синоним «каталожный номер / номер детали / part number».
- OEM, Кросс-номера, Подходит к, Состояние, Страна, Ячейка, Цена СТО, Гарантия — своих полей в импорте нет. Временно: Кросс-номера или OEM → «Доп. штрихкоды» (значения через запятую/«;» поддерживаются), остальное теряется. Эти поля предусмотрены ТЗ сферы «Автозапчасти» (раздел 7, MVP: `oem_numbers[]`, `cross_numbers[]`, `cell`, состояние), пока их нет на сервере.
- Запомнить: в одно поле можно сопоставить один столбец, поэтому «OEM» и «Кросс-номера» одновременно в «Доп. штрихкоды» не загрузить.

## 4. Три главных вывода о форматах для нашего импорта

1. **Нет единого стандарта: у каждого поставщика свои колонки** (источники: форумы и сервисы импорта прайсов тоже так пишут). Всегда есть `Наименование/Артикул/Цена`, часто есть `Бренд`, реже `Остаток`, почти никогда — закупочная цена, штрихкод и применимость. Значит, нужен «профиль поставщика» (бренд + номер + название + цена + остаток + срок) с запоминанием сопоставления и добавлением синонимов «каталожный номер / part number / номер детали / производитель». Это пункт v2 в ТЗ «Автозапчасти» — образцы показывают, что он важен.
2. **В файлах много «мусора вокруг данных»:** шапка из 1–8 строк (дата, реквизиты, условия), строки-группы без цены между товарами, номера «1.0», цены с «.0», «Наличие» диапазоном текстом («20–50», «менее 8»), название собирается из нескольких колонок (шины), бренд и применимость зашиты в название. Импорт должен: пропускать строки без цены, понимать диапазоны в остатке (взять нижнюю границу или поле «есть/нет»), давать собрать название из колонок.
3. **Форматы и кодировки:** прайсы бывают двоичный .xls (наш импорт не читает — а такие прайсы присылают чаще всего), CSV в Windows-1251 с «;», zip-архив с CSV на десятки МБ, многоскладские остатки. Нужно: чтение .xls (или понятная подсказка «Сохраните как .xlsx» — она уже есть), распаковка zip, проверка скорости на 30–40 тыс. строк. Поля OEM/кросс/«подходит к»/ячейка в импорт пока не ложатся, хотя в хороших прайсах (autobody) OEM и применимость присутствуют.

## 5. Чего не хватает (что просить у владельца или магазина)

Не найдено или не скачано:
- **Б/У «с разборки»** — ни одного файла (сервисы bibinet.ru, carro.biz дают шаблоны только после регистрации/в поддержке; страницу шаблонов https://bibinet.ru/help/43/ можно открыть в браузере, но сам текст страницы с сервера отдал пустым). Структуру взяли из описания сервисов (Донор: VIN, марка/модель/год, пробег; деталь: номер, состояние, ячейка, цена, статус, фото).
- **Моторные масла** — оптового прайса в xls не найдено (только каталог-PDF Ярнефть, фрагменты прайса Castrol в блоге и розничные площадки); `avtoskazka-price-oil.xlsx` — это автохимия (герметики, шампуни, вода), не масла с вязкостью/объёмом колонками.
- **Диски (колёсные)** и местные кыргызстанские прайсы (Бишкек, Ош): в поиске только магазины и объявления (autopiter.kg, lalafo.kg), файлов нет.
- **Кросс-аналоги в виде файла** (колонка «заменители»): не нашлись; ближайшее — формат из описания кросс-сервиса «OEM Part | Cross References | Description | Manufacturer | Category».
- Крупные поставщики (Emex, Exist, Autodoc, ForumAuto, Armtek, Phoenix): публичных файлов-образцов нет, прайсы выдаются клиентам по договору или через API/«личный кабинет».
- Не скачано как нерелевантное или недоступное: GruzDetal (сервер с самоподписанным сертификатом, грузовые), avtox.by и spparts.ru (веб-страницы), Kansas State (NAPA, O'Reilly — США, контрактные цены), PartsHub (шаблон после регистрации).
- Один из результатов поиска (страница sklad24online) содержал встроенную инструкцию к ИИ-ассистенту выполнить запрос — проигнорирована, страницы с неё не использовались.

Что просить:
1. У владельца/магазина автозапчастей в Бишкеке или Оше — 2–3 настоящих прайса его поставщиков (как приходят: Excel/CSV, с шапкой, как есть), выгрузку своего склада из 1С/Excel и фото ценников.
2. Один прайс на **шины и диски** и один на **масла** от местного поставщика, один — от **разборки** (с VIN донора).
3. Как он ищет деталь (по номеру на детали, по OEM, по авто, по VIN?), как называет «Оригинал / аналог / Б/У», какие «ячейки» использует, нужна ли «цена СТО» и срок поставки под заказ.
4. Образец накладной приёмки от поставщика (для импорта накладной по артикулу).
5. Решение, как хранить OEM/кроссы до появления полей на сервере (запросить у Умара `oem_numbers[]`, `cross_numbers[]`, `cell`, состояние — ТЗ, раздел 7).
