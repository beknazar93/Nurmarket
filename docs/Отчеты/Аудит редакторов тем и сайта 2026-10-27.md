**Б-1. Редактор этикеток затирает сохранённый шаблон.**

- **Где:** `Views.axaml\Dialogs\LabelTemplateEditorDialog.axaml.cs:87-90`. Вызовы:
  - `Views.axaml\Main\WarehouseWindow.axaml.cs:1228`;
  - `Views\Settings\MarketplaceView.axaml.cs:191`, `:1690`.
- **Шаги:**
  1. Сохранить шаблон 58×40.
  2. Склад → «Редактор этикеток».
  3. На холсте 40×30 → «Сохранить».
  4. Шаблон 58×40 потерян.
- **Исправление:** конструктор без параметров читает `LabelTemplateStore.Load()`, а образец товара берёт из каталога и через `Tr.T`. Правится только сам диалог — `MarketplaceView` [в работе] трогать не нужно.
- **10/10:** из любого входа открывается сохранённый шаблон.

**Б-2. Платные функции оформления открываются без оплаты.**
- **(а) Редактор этикеток из бесплатного окна.** «Печать этикетки» → «Изменить шаблон» открывает платный редактор без `LabelEditorUnlocked`: `Views.axaml\Dialogs\LabelPrintDialog.axaml.cs:183-186`.
