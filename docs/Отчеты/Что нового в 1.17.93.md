# Что нового в 1.17.93 (обычный выпуск для клиентов)

Выпуск 22.11.2026 по команде владельца «выгружай». Windows, Android, Linux. Мобильное приложение — отдельно, 1.18.23. Номер: 1.17.92 -> 1.17.93, Android versionCode 11793.

## Для клиента

1. **Приёмка: категория.** У нового товара выпадающий список существующих категорий.
2. **Приёмка: единица.** Выбор единицы открывается списком поверх карточки и ничего не двигает.
3. **Штрихкод.** Кнопка «Сгенерировать штрихкод» больше не вызывает ошибку — ни в «Приёмке», ни в «Закупки → Приём товара».
4. **Срок годности и партия.** С выбранным поставщиком вводятся прямо в карточке; без поставщика — понятная подсказка; при потере введённых данных касса предупреждает.
5. **Загрузка накладной.** Новый диалог «Столбцы накладной»: столбцы определяются сами, списки с примерами, живой предпросмотр, «Количество = 1 для всех», подсказки, чего не хватает.
6. **Штрихкоды.** После выбора товара поле поиска очищается и фокус возвращается; список заполняет окно на экранах 1024×600.
7. **Печать этикетки.** Вернулась в меню «⋯» у товара (Склад → Товары).
8. **Весы.** Список виден целиком, есть прокрутка, понятное сообщение про IP весов.
9. **Настройки.** Ложное «Есть несохранённые изменения» (в «Обновления» и других разделах) исчезло.
10. **Возврат продажи.** Исправлено падение в окне возврата.

Мобилка 1.18.23: сферы «Базар» и «Автозапчасти» определяются по ответу сервера (выбора нет), поиск по каталожному номеру/OEM.

## Что не проверено вживую

- Выбор единицы (всплывающий список), печать на Xprinter, сенсорный экран, весы, eKassa.
- Android и Linux на устройствах.
- Кнопка «Обновить» с 1.17.92 на 1.17.93.
- Срок годности без поставщика: ждёт полей на сервере (пока только подсказка).
- 240 снимков экрана (ScreenSnapshotTests) красные намеренно; эталоны не пересоздавались. В выпуск не входят.
