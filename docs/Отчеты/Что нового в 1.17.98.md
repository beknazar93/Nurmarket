# Что нового в 1.17.98 (обычный выпуск для клиентов)

Выпуск 27.11.2026 по команде владельца «Выгрузи». Windows, Android, Linux. Мобильное приложение в выпуск не входит. Номер: 1.17.97 -> 1.17.98, Android versionCode 11798.

## Для клиента

1. **Избранные товары.** Товары с ★ снова стоят в каталоге первой группой «★ Избранные» (в 1.17.97 их разбросало по категориям).
2. **Кнопка «🏷 Ценники» в приёмке.** Есть в «Закупки → Приём товара», в накладной прихода и в «Склад → Приёмка». Открывает «Ценники и штрихкоды» с товарами накладной, копий столько, сколько принято. Печатать можно термоэтикеткой и листом A4, шаблон и рамка — из редактора.
3. **Аналитика товаров в программе владельца.** «Отчёты → Аналитика → Склад»: 11 плиток (товаров, единиц, стоимость по закупке и по продаже, наценка, нет в наличии, заканчивается, в минусе, без цены, без штрихкода, без категории), категории с долями, списки «Заканчивается» и «Нет в наличии», топ-20 по стоимости, выгрузка в Excel. Закупочные цифры — только при праве на закупку.
4. **Редактор ценников на любом тарифе.** Входит в «Стандарт», отдельная покупка не нужна.
5. **«История чеков».** Если сервер не ответил или за период не вернул чеков, показываются продажи, проведённые на этой кассе, с плашкой; в журнал пишется строка `[SALES]` (на каком шаге чеки отсеялись). Раньше было «чеков нет».
6. **Вход по QR-бейджу с настоящего сканера.** Символы приходят по нажатиям клавиш, конец — Enter или Tab; бейдж читается целиком и входит сразу, секрет не попадает в «штрих-код» и в поля; после неудачного скана можно сразу сканировать ещё раз.
7. **Мелочи.** Заголовки категорий в табличном виде тёмной темы читаются; кнопка «+» в «Карточках» не закрывает цену; окно «QR для входа» (программа владельца) шире — кнопки не обрезаются.

## Что не проверено вживую

- Вход по бейджу с настоящим USB-сканером (проверено сообщениями окну и тестами).
- Кнопка «Ценники» из приёмки на живой накладной NBS; печать A4 с рамкой на принтере.
- Аналитика: раскрытие категорий и фильтры на живых данных, право «без закупки», Excel в самом Excel.
- «История чеков» на живом сервере в состоянии «пусто».
- Android и Linux на устройствах; кнопка «Обновить» с 1.17.97.
- 240 снимков экрана (ScreenSnapshotTests) красные намеренно, эталоны не пересоздавались.
