# Что нового в 1.17.94 (обычный выпуск для клиентов)

Выпуск 22.11.2026 по команде владельца «выгрузи». Windows, Android, Linux. Мобильное приложение в этот раз не менялось (остаётся 1.18.23). Номер: 1.17.93 -> 1.17.94, Android versionCode 11794.

## Для клиента

1. **Печать этикетки.** Пункт «Печать этикетки» в меню «⋯» у товара теперь открывает окно «Штрихкоды» с уже выбранным товаром, а не печатает молча.
2. **Товары: галочки выбора.** Вернулись галочки в строках, «выбрать все», счётчик выбранных и панель «Ценники и штрихкоды»; в плитках галочка в углу.
3. **Штрихкоды: вид «Список / Плитки».** Список быстро работает даже на 15 000 товаров; выбор и число копий общие для обоих видов.
4. **Приёмка.** Кнопка «Убрать» убирает последнюю строку; Ctrl+Z возвращает убранное сразу пачкой.
5. **Остаток в минусе.** Показывается «Минус −N шт.» красным (плитка, список, упаковка, карточка, «Склад → Товары»). Исправлено «0 шт.» вместо минуса. Остаток после продажи уходит ниже нуля только при включённой настройке «Продавать без остатка».
6. **«Смета» и «Прокат».** Больше не показываются по старому признаку, если сервер сказал «выключено».
7. **Маркетплейс.** У каждой из 20 функций своя иконка и описание: что делает, как включить, для кого.

## Что не проверено вживую

- Всплывающие списки, сенсорный экран, печать на Xprinter, весы, eKassa.
- Android и Linux на устройствах.
- Кнопка «Обновить» с 1.17.93 на 1.17.94.
- Ctrl+Z и «Очистить список» в приёмке; вид «Список» в «Штрихкодах» на реальном экране.
- Красные тесты (см. итоговый отчёт выпуска); 240 снимков экрана (ScreenSnapshotTests) красные намеренно, эталоны не пересоздавались.
