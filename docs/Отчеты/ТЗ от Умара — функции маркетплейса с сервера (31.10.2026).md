# ТЗ: функции маркетплейса — с сервера (касса и программа владельца)

Дата: 31.10.2026. От: Умар.

## Зачем

Маркетплейс теперь есть и в веб-админке (front-market, раздел «Маркетплейс», пока «Бета-тест").
Клиент смотрит функции там, нажимает «Подключить» — заявка уходит в поддержку, поддержка принимает оплату
и включает функцию **на сервере**. Сейчас касса узнаёт о купленном только по ключу активации на этом компьютере,
поэтому купленное через сайт в кассе не появится. Нужно, чтобы касса брала включённые функции с сервера.

Ключи активации (LicenseKeys) не убираем — они работают как раньше. Сервер — второй источник: функция
открыта, если есть действующий ключ **или** она включена на сервере.

## Что уже есть на сервере (ничего ждать не нужно)

`GET /api/users/company/addons/` (с токеном) →

```json
[
  { "code": "kassa-loyalty", "active": true,  "until": null },
  { "code": "kassa-scales",  "active": true,  "until": "2026-12-31" },
  { "code": "analytics",     "active": false, "until": "2026-10-01" }
]
```

- `active: true` — функция действует (сервер уже учёл срок `until`). `false` — выключена или срок вышел.
- В списке бывают и коды веб-админки (`analytics`, `procurement`, `clients` …) — касса их просто пропускает.

## Коды функций кассы

Код на сервере = `kassa-` + id карточки в MarketplaceCatalog.cs:

| Карточка | Код на сервере |
|---|---|
| Программа лояльности (`loyalty`) | `kassa-loyalty` |
| Табель (`timesheet`) | `kassa-timesheet` |
| Аналитика склада (`analytics`) | `kassa-analytics` |
| Редактор ценников (`pricetag`) | `kassa-pricetag` |
| Массовые ценники (`bulktag`) | `kassa-bulktag` |
| Редактор этикеток (`labeleditor`) | `kassa-labeleditor` |
| Весы (`scales`) | `kassa-scales` |
| Выгрузка (`export`) | `kassa-export` |
| Telegram-бот владельца (`telegram`) | `kassa-telegram` |
| Статистика смен (`shiftstats`) | `kassa-shiftstats` |
| Языковой пакет (`language`) | `kassa-language` |

Если появится новая платная карточка — код по тому же правилу, и скажите нам: добавим её в веб-каталог.

## Что сделать в кассе

1. **Загрузка.** После входа и потом раз в 15 минут (и при открытии окна «Маркетплейс») — `GET users/company/addons/`.
   Сохранить ответ в локальный кэш вместе со временем загрузки.
2. **Офлайн.** Нет сети — брать кэш. Кэш старше 7 дней не продлевает доступ: функции с `until` в прошлом закрыть,
   бессрочные (`until: null`) держать по кэшу.
3. **Проверка доступа.** Функция открыта, если: действующий ключ (как сейчас) **или** в последнем ответе/кэше
   `code = kassa-<id>` и `active: true`. Это место одно — TariffGate / проверка `*Unlocked` в настройках.
4. **Выключили на сервере** (`active: false` или кода нет) и ключа нет — функция закрывается при следующей
   загрузке. Данные функции (бонусы, табель…) не удалять, только скрыть.
5. **Окно «Маркетплейс».**
   - Включено на сервере — значок «Подключено», без ввода ключа.
   - Кнопка «Подключить» (рядом с вводом ключа): заявка в поддержку тем же запросом, что у сайта:
     `POST /api/support/addon-requests/` (с токеном)
     `{ "item": "kassa-loyalty", "title": "Программа лояльности", "price": "1 500 сом разово", "phone": "+996…", "comment": "" }`
     → 201 `{ "ok": true }`; 400 — телефон короче 9 цифр; 429 — больше 5 заявок за 10 минут; 503 — показать телефон
     поддержки из ответа (`phone`).
   - Под кнопкой: «Оплата пока через поддержку: оставьте заявку — перезвоним, примем оплату и включим функцию».
6. **Без сервера ничего не ломать:** 401/404/500 на `company/addons/` — работать по ключам и кэшу, без ошибок на экране.

## Как проверить

- Тестовый аккаунт market@nur.kg (пароль — у Умара). Мы включим ему `kassa-loyalty` на сервере.
- Без ключа «Программа лояльности» должна открыться после перезахода (или через ≤ 15 минут).
- Выключим на сервере — закрывается при следующей загрузке, данные бонусов на месте.
- Без интернета — работает по кэшу.

## Что делаем мы (сайт и сервер)

- Веб-маркетплейс уже показывает «Подключено» по этим же кодам.
- Поддержке — удобное включение функции по заявке (сейчас вручную в админке: «Платные функции компаний»).
- Позже — онлайн-оплата; для кассы ничего не изменится, она всё так же читает `company/addons/`.
