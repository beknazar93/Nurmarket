## Как запускать
```
powershell -ExecutionPolicy Bypass -File tools/qa/mobile-e2e.ps1
```
Ключи: `-Window` (показать окно эмулятора), `-KeepEmulator` (не гасить после прогона), `-Port 18080`, `-Test integration_test/app_e2e_test.dart`.
Скрипт: берёт замок `Global\NurMarketBuildLock` (на время прогона других сборок быть не должно — ПК слабый) → поднимает
`Pixel_7_API_35` холодным (`-no-snapshot -no-snapshot-save -gpu swiftshader_indirect -memory 2048 -no-audio -no-window`) → на время
прогона снижает порог хранилища Android (`sys_storage_threshold_*`, потом возвращает) и выключает анимации → 
`flutter test integration_test/app_e2e_test.dart -d emulator-5554 --dart-define=NURMARKET_API_URL=http://127.0.0.1:18080` →
гасит эмулятор, отпускает замок, пишет «E2E ИТОГ». Время: загрузка эмулятора ~1 мин, сборка debug-APK ~4 мин, сами сценарии ~1 мин.
Если эмулятор уже запущен, скрипт берёт его и не гасит.

Вручную (эмулятор уже работает): `cd NurMarketMobile; flutter test integration_test/app_e2e_test.dart -d emulator-5554 --dart-define=NURMARKET_API_URL=http://127.0.0.1:18080`.
Без `--dart-define` тест остановится сразу с понятным сообщением (не пойдёт в боевой адрес).

## Что сделано в коде
- `lib/core/api/api_client.dart`: `defaultBaseUrl = String.fromEnvironment('NURMARKET_API_URL', defaultValue: 'https://app.nurcrm.kg')`.
  Без define (боевая сборка, release) — прежний адрес, поведение не меняется. Тот же адрес использует фоновая отправка очереди и ссылки на фото.
- `pubspec.yaml`: dev-зависимость `integration_test` (из Flutter SDK, в сборку приложения не входит).
- Ключи (`Key`) у кнопок: `loginEmail`, `loginPassword`, `loginSubmit`, `openShiftBtn`, `salePayBtn`, `doPayBtn`, `newCheckBtn`, `checkReturnBtn`, `returnAllBtn`.
- `integration_test/support/fake_nur_server.dart` — поддельный сервер на `dart:io HttpServer` (127.0.0.1 устройства): вход (токены), профиль, компания,
  касса, смены (открыть/закрыть/список), каталог из 14 товаров (один весовой — сыр 75 сом/кг), checkout с итогом по правилу сервера
  (весовые строки суммой вниз до копейки, остальные HALF_UP) и ключом повтора (Idempotency-Key: тот же ключ — тот же чек), список/карточка чека,
  возврат. Неисправности по заказу теста: 500/503, медленный ответ, «продажа записана, ответ оборван», «сервер недоступен» (порт закрывается).
- `integration_test/support/harness.dart` — запуск приложения как в `main()`, но база в памяти и вход в памяти (защищённое хранилище телефона не трогается).
- `integration_test/app_e2e_test.dart` — сценарии.

## Замечания
- На эмуляторе `/data` почти полон (185 МБ свободно): `flutter test` сам удаляет прежнюю установку `kg.nurcrm.nurmarket` (подпись debug не совпадает с release) —
  после прогона на эмуляторе стоит debug-сборка без данных, релизное приложение придётся ставить заново.
- Скрипт при занятом замке `Global\NurMarketBuildLock` ждёт до ~8 минут (как `build-locked.ps1`) и выходит с кодом 3.
- Адреса, которых поддельный сервер не знает (задачи, app-settings, лента `changes`, `variants`), отвечают 404 — это фоновые экраны; список печатается в конце прогона.
