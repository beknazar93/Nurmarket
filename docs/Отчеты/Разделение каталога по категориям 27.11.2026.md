# Разделение каталога по категориям — 27.11.2026

Просьба владельца (фото кассы магазина, плитки сплошной сеткой): «Добавь линии, разделение по категориям».

## Что сделано

- В каталоге кассы плитки идут **группами по категориям**. Над каждой группой — полоса заголовка: цветная метка (тот же цвет, что у шапки плиток этой категории), **название категории**, **число товаров** в ней (по текущему отбору, на всех страницах) и **тонкая линия** до правого края. Каждая категория начинается **с новой строки**. Товары без категории — группа **«Без категории»** в конце (ky «Категориясыз», en «No category», tr «Kategorisiz», uz «Kategoriyasiz»).
- Работает и в **плитках**, и в **списке строками** (на окне уже 1280 касса сама показывает список — на 1024×600 заголовки тоже есть), и в раскладках «Карточки» и «Минимал».
- Внутри категории порядок прежний: «сначала без штрихкода» (если включено) → избранные → по названию.
- Вкладки «Все товары / Весовые / Штучные / Поштучно / Комплекты / Услуги» — группировка **внутри выбранной вкладки** (счётчик — по вкладке).
- Заголовок **не кликабелен** (нажатие не ловит, не мешает плиткам; сворачивание групп не делали — усложнило бы страницы).
- Стрелки клавиатуры: при разделении ряды неровные, поэтому Вверх/Вниз идут по координатам (ближайшая плитка соседнего ряда), за краем страницы — листание, как раньше.

## Логика по умолчанию

Группировка включается, только если всё сразу:
1. настройка **«Разделять каталог по категориям»** включена (по умолчанию — **вкл.**);
2. в каталоге магазина есть **хотя бы две разные категории** (магазин без категорий видит каталог как раньше — так «вкл. для сфер, где у товаров есть категории» решается по самим данным, без списка сфер);
3. **нет поиска по тексту** (2+ символа): результат поиска идёт по совпадению (точные/«начало слова» выше), группы сломали бы релевантность;
4. в окне «Фильтр» не выбрана **одна категория** и не выбран вид **«Избранные»**; не открыта одна категория в плитках категорий «Базара» — там группа была бы одна.

## Страницы

- Страница — 50 «мест» (на телефоне — меньше, как раньше): плитка — одно место, заголовок — тоже одно. Каждая страница начинается с заголовка (у продолжения группы с прошлой страницы — тот же заголовок).
- Заголовок новой группы **не остаётся в конце страницы**: если под ним на этой странице не помещаются хотя бы 2 плитки (или вся группа, если она меньше), группа начинается со следующей страницы.
- «Страница N из M» считает страницы по этим правилам; каждый товар попадает ровно на одну страницу.
- Без группировки страницы те же, что раньше (по 50 товаров).

## Скорость (15 000 товаров)

- Ключ категории добавлен в ту же сортировку отбора (она уже считается в фоне на больших каталогах). Страницы и счётчики считаются **один раз на отбор** (O(n)); смена страницы берёт готовые.
- Заголовки рисует сама панель плиток (без лишних элементов на группу); пересчёт — только при новой раскладке (страница, ширина, отбор), не на каждый кадр. На странице не больше 50 плиток.
- Тест: отбор с группировкой 15 000 — < 2 с (фон), страницы + счётчики — < 150 мс (по факту единицы мс).

## Настройка

Настройки → Экран: переключатель **«Разделять каталог по категориям»** с пояснением (5 языков, Tr.T). Применяется сразу, без «Сохранить». Та же страница «Экран» открывается и в программе владельца. Значение хранится в `user-settings.json` (`CatalogGroupByCategory`) и синхронизируется между устройствами пользователя как личная привычка (`SettingsCloudSync`, рядом с «Сначала товары без штрихкода»).
