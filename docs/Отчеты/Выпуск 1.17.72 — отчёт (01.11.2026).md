## Замечания

- Сеть периодически даёт ошибку проверки сертификата (`CERTIFICATE_VERIFY_FAILED`) — первый запуск `gh_release.py release` упал на ней до создания выпуска, повтор прошёл без последствий. Остальные запросы шли с повторами.
- `pack_linux.py` по-прежнему называет архив с суффиксом `-adapt` (строка 58) — выложен под штатным именем.
- Для Android-кассы использовался `-p:JavaSdkDirectory` на JBR из Android Studio. Пароль ключа читался из README без вывода.
- Проверка настоящего обновления Windows (4.3, шаг 8) не выполнялась.
- Этот отчёт создан после коммитов и не закоммичен.

## Сделать стабильными

`PATCH https://api.github.com/repos/beknazar93/<репозиторий>/releases/<id>` с телом `{"prerelease": false, "make_latest": "true"}` (токен из `token.txt`, в вывод не печатать). Порядок: Android, Linux, macOS, затем Windows (после него кассы стабильного канала увидят обновление). Мобилка остаётся тестовой. `gh_release.py update` не подходит — он принудительно ставит prerelease=true.

## Откат

Выпуски не удалять. Пока они prerelease, стабильные кассы их не видят. Спрятать: `PATCH` с `{"prerelease": true}` или `{"draft": true}`. Тестировщикам вернуться на 1.17.71/1.17.70 можно установкой `NurMarketKassa-win-Setup.exe` из соответствующего выпуска.
