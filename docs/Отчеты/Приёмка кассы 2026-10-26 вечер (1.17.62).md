## 2. Дефекты

### Д-4 (средний, безопасность) — ключ Gemini читается через UI Automation, хотя на экране скрыт
- **Где.** Окно «Ключи Gemini»: Нур Советник ⚙ → «Ключи Gemini…» и Настройки кассы → Операции → «Несколько ключей…».
- **Шаги.**
  1. Открыть окно.
  2. Любым UIA-клиентом (Inspect, pywinauto, экранный диктор) прочитать `ValuePattern.Value` у поля `key` («Ключ 1»).
- **Факт.** Возвращается весь ключ открытым текстом. На экране при этом точки, а кнопка «Показать» не нажата.
- **Почему важно.** Любая программа на ПК без прав администратора читает секрет. То же, скорее всего, касается других полей с `PasswordChar`: ключи ИИ в настройках, токен бота. Проверьте их тем же способом.
- **Что случилось при проверке.** Значение ключа один раз попало в консольный вывод агента. В файлы, снимки и этот отчёт оно не записано. Если для вас это важно, ключ можно перевыпустить.
- **Ожидается.** Пока ключ скрыт, UIA отдаёт пустое значение или маску. Пример — `PasswordBox` в WPF.

### Д-5 (средний) — экран покупателя не открылся при запуске и позже пропал сам
- **Настройки.** `CustomerDisplay.IsEnabled = true`, второй монитор T19B300 подключён всё время.
- **При запуске (22:09).** Окна «Экран покупателя» не было. Причину журнал не пишет: `MainWindow.axaml.cs:2210` записывает в журнал только неудачу на событии смены экранов, а при запуске итог `OpenForSession` не пишется вообще.
- **Ручное открытие.** Кнопка «Экран» в 22:39 открыла окно — всё работало.
- **Пропажа.** Между 22:43 и 00:51 окно исчезло. Смена не закрывалась, кассу не трогали, записей `CUSTOMER_DISPLAY` в журнале нет.
- **Оговорка.** Кассу запускал `deploy_both.ps1` через WMI, и окно кассы стояло свёрнутым. При обычном запуске может не повториться. Пропажу ночью могло вызвать отключение второго монитора энергосбережением (`Screens.Changed` → `Hide`), а при возврате монитора окно не открылось снова.
- **Как воспроизвести.**
  1. Запустить кассу с включённым экраном покупателя — штатно, с ярлыка.
  2. Проверить, что окно открылось.
  3. Выключить и включить второй монитор (или дождаться его сна).
  4. Окно должно вернуться само.
