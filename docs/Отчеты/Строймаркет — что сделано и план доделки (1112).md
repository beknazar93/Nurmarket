## 0. Коротко

- **Готово примерно на 25 % по пакетам ХМ** (ХМ1 — полностью; ХМ2 — код готов, но выключен; ХМ5 — около 70 %; ХМ4 — частично). Если считать потребности П1–П15 вместе с общими функциями кассы (долг со сроком, рассрочка, КП/счёт, услуги, опт, комплекты, весы), покрыто около 40 %.
- **Магазин этого пока не видит.** Сферу «Хозтовары» нельзя выбрать ни в окне первого запуска, ни в Настройках — только назначением техподдержки. Дробное количество выключено флагом. Калькулятор открывается только у товаров с описанием.
- **Сервер почти готов по структуре** (проверка 01.11): у товара есть `unit_code / quantity_step / min_sale_quantity`, `prices[] / volume_prices`; у клиента — `price_level / credit_limit / default_due_days / client_kind`; есть `objects`, `customer-orders`, `batches`, `cut`, `storage_location`, `related`; профиль `hardware` есть в `sphere-profiles`. Но флаг компании `hardware_2026_11:false`, запись нигде не проверялась, `market_profile` нет. Касса ничего из этого не читает.
- **Топ-5 доделок:** (1) выбор сферы и переключатель размера; (2) включение дробного после живой проверки Б-52 на «Хозмаг тест»; (3) окно «Количество / длина / Д×Ш»; (4) скан коробки = N штук; (5) доделка калькулятора (вход из каталога, «В чек» при выключенном дробном, нормы владельца). Сразу за ними — цена прораба и ценник «за м² и за упаковку».
