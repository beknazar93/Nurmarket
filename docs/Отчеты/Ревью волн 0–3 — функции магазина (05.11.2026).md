### С12. Большие выгрузки MiniExcel: числа и даты должны остаться числами
- `Infrastructure/Services/LargeExcelWriter.cs:36` (`DynamicExcelColumn.Format`), `:93-94` (дата → серийное число), `:116-121`.
- **Риск:** часть версий MiniExcel применяет `Format` через `IFormattable.ToString(format)` и пишет ТЕКСТ. Тогда суммы не считаются, а дата (double с форматом `dd.mm.yyyy`, где в .NET `mm` — минуты) превращается в мусор. Тест `Write_AppliesColumnNamesAndNumberFormats` ищет только строку формата в XML, а не тип ячейки.
- **Совет:** в тесте проверить у ячейки денег отсутствие `t="str"`/`t="inlineStr"` и наличие `s=` со стилем `numFmt`. Если окажется, что пишется текст, — использовать `ExcelFormatId`/`DynamicExcelColumn` с числовым id формата.
- **Нужна проверка вживую:** ревизия больше 5000 строк → открыть в Excel → «Сумма» по колонке цены и фильтр по дате.
