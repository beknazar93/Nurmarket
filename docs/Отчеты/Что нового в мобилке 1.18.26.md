# Что нового в мобилке 1.18.26

27.11.2026, обычный выпуск для клиентов (по слову владельца). Номер: 1.18.24+25 -> 1.18.26+27 (1.18.25 отдельно не выкладывалась, её исправление вошло сюда). Режим тестировщика только по коду. Подпись — ключ мобилки, ставится поверх 1.18.x, вход сохраняется.
Описание для GitHub на 5 языках: `NurMarketMobile/release-notes-mobile-1.18.26.md`.

## Для клиента

1. **Аналитика склада.** «Управление» → «ИИ и аналитика» → «Аналитика склада» (владелец и администратор): сколько товаров и единиц, стоимость по продаже и закупке, наценка, нет в наличии / заканчивается / в минусе, товары без цены и штрихкода, доли по категориям, топ-10 по стоимости остатка, последние поступления. Плитка со счётчиком открывает «Склад» с тем же фильтром. Закупка, наценка и поступления — только тем, кто видит закупку. Без связи — данные телефона с пометкой «Остатки на …». Подробности — «Аналитика склада в мобилке 27.11.2026.md».
2. **Связь с кассой по QR.** Камера читает QR кассы с экрана ноутбука (Full HD, автоприближение), через 8 секунд без результата — подсказка и «Сфотографировать QR»; если касса не ответила — причина (другая сеть, брандмауэр, приём выключен, код устарел). Нужна касса 1.17.97 или новее.
3. Нур-советник открывает «Аналитику склада» по просьбе.

## Что не проверено вживую / риски
- Настоящий телефон (камера, QR кассы), живой аккаунт NBS (цифры аналитики не сверялись с сайтом).
- Скорость на складе в 15 000 товаров не измерялась.
- Полный `flutter test` не гонялся — только новый тест аналитики и выборочные.
