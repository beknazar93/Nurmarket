## Найденные дефекты по серьёзности

**Средние**
- **Д-2. Табель показывает больше 24 часов в день.** У Nur Test: 01.11 — «~28,1», 05.11 — «~27,2», 10.11 — «~41,6» ч. Похоже, смена, открытая несколько суток, целиком записывается на день открытия. Функция 1.17.83, не 1.17.85. Снимок 17.
- **Д-5. Касса: ложное «Есть несохранённые изменения».** В «Настройках кассы» я только переключил вкладки «Весы на кассе» ↔ «Весы с этикетками» (ничего не менял) — при «Закрыть» окно спросило «Закрыть без сохранения?». Нажал «Закрыть без сохранения», значит ничего не записалось. Снимок 28.

**Низкие**
- **Д-3. Склад → Приёмка (пустая):** содержимое вкладки отцентровано по высоте — полоса вкладок съезжает вниз примерно на 190 px по сравнению с «Товарами», сверху и снизу пусто. Снимок 06 (сравните с 05). В «Закупки → Приём товара» окно заполнено нормально (07).
- **Д-4. Табель:** серая шапка окна пустая (нет заголовка), вокруг карточки широкие чёрные поля. Снимок 17.
- **Д-6. Экран покупателя закрылся сам** через 21 с после запуска кассы. В журнале «Закрыт вручную (кнопка «Экран», Esc или настройки)», но в кассе я в это время ничего не нажимал — только снимок PrintWindow. Перед этим на 17 с открывалось окно PosAlertDialog (что в нём было, не видел — к моменту снимка оно уже закрылось). По журналу, экран сам откроется при открытии смены или следующем запуске. Причина не выяснена.
- **Д-7. Окно возврата:** номер прошлого возврата показан как технический id — «Возврат №7328e9cf · 170,00 сом». Снимок 12.
- **Д-8. «Продажи»:** кнопки «Возврат» в колонке не на одной вертикали (у чека без возврата кнопка левее). Снимок 08.
- **Д-9. Фильтры возврата:** поле «до» и «Сбросить» переносятся на вторую строку, «Сумма от» и «до» разорваны. Снимок 13.
- **Д-10. Касса, «История чеков»:** окно 1904×1016 стоит в левом верхнем углу (0,0), справа остаётся полоса 16 px — не по центру. Снимок 22.
- **Д-11. Касса, «Возврат» при закрытой смене:** только мелкая зелёная строка «Откройте смену, чтобы оформить возврат.» под кнопками чека, а плитка «Возврат» в меню выглядит активной. Снимок 24.
- **Д-12. Доступность:** вкладки «Весы на кассе / Весы с этикетками / …» в UI Automation выбираются (IsSelected меняется), но содержимое не переключается — работает только настоящий щелчок. Для программ чтения с экрана вкладки по сути не работают. В окне возврата у флажков строк пустое имя.
- **Д-13. Настройки → Печать:** текст «меняется ниже, в блоке «Оборудование»», а такого блока на странице нет; подсказка «выберите принтер в Настройки → Печать → …», хотя вы уже на этой странице. Снимок 27.
