# Что нового в 1.17.96 (обычный выпуск для клиентов)

Выпуск 27.11.2026 по команде владельца «выпусти». Windows, Android, Linux. Мобильное приложение не менялось. Номер: 1.17.95 -> 1.17.96, Android versionCode 11796.

## Для клиента

1. **Смешанная оплата без связи.** Раньше при «Автономно» касса отказывала: «Смешанная оплата недоступна, пока сервер NurCRM не отвечает». Теперь чек встаёт в очередь, как наличные, и потом уходит на сервер с разбивкой наличные/безнал, без дублей. «Касса:» прибавляет только наличную часть. Проверено вживую на NBS: 40 наличными + 100 безналом без связи, после связи дошло на сервер, X-отчёт показал 40/100.
2. **Меньше ложных «аварий сервера».** Один быстрый ответ 500 на фоновый запрос больше не переводит кассу в «Автономно». Обрывы, таймауты, 502–504 и ошибки на оплате считаются, как раньше.
3. **Вход по QR-бейджу.** Программа владельца → Настройки → Сотрудники → «QR для входа»: выпустить бейдж (срок и PIN по желанию), сохранить картинку, распечатать. Кассир подносит бейдж к сканеру на экране входа — касса открывается от его имени. Потерял бейдж — «Отозвать». В первый раз на каждой кассе нужен пароль один раз. После 5 неудач подряд — пауза (защита от перебора).
4. **Редактор ценников и штрихкодов — 7 исправлений.** Правки доходят до «Печати» без «Сохранить»; кнопка «Штрих-код» выбирает штрихкод, а не убирает его; поле «Толщина штриха» и подсказка, если штрих слишком тонкий; галочки в «Печати» не ломают свой шаблон; при смене размера элементы растягиваются и не уходят за край; поля X/Y/ширина/высота показывают настоящее значение; у QR лишние настройки отключены.
5. **Мелкие исправления.** «Просмотр смены» у владельца показывает «Расход» по данным сервера (раньше «—»); экран покупателя «Классика» без пустой заглушки; в «Тех поддержке» одна главная кнопка; в «Возврате» колонка «Товар» и дата 150 px; подтверждения внесения/изъятия не вешают Диктор.

## Чего в этом выпуске НЕТ

- Смены кассира бейджем на уже открытой кассе (только на экране входа). Касса подсказывает: «☰ → Сменить кассира».
- Входа по бейджу на новой кассе без пароля — нужен сервер (ТЗ Умару «вход кассира по QR-бейджу», не отправлено).

## Что не проверено вживую

- Настоящий телефон (Android) и Linux на устройствах; кнопка «Обновить» с 1.17.95 на 1.17.96.
- Диктор (чтение с экрана) на внесении/изъятии и закрытии смены — исправлено в коде, проверено только тестами.
- Скан QR-бейджа на открытой кассе — проверен только UI-тестом (вход по бейджу на экране входа проверен вживую).
- «Просмотр смены» у владельца, экран покупателя «Классика», окно «Возврат» — вживую не смотрели.
- Печать ценников на настоящем принтере (проверено через PDF).
- 240 снимков экрана (ScreenSnapshotTests) красные намеренно, эталоны не пересоздавались.
