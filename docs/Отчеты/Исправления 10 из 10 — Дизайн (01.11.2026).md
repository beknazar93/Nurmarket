- **Пути по коду:** мышь/касание: нажатие → клик → фокус в поле → цифры и Enter идут в поле/«Применить». Клавиатура: Tab на «%» → цифра уходит в поле; Enter → применение; Пробел → режим и фокус в поле; ←/→ → режим без потери фокуса на переключателе. Снять вживую: мышью «%» → ввести 10 → Enter; касанием «сом» → цифры; Tab → «%» → Enter.

- **Уточнение по живой проверке круга 3 (окно скидки):** Enter на «%» / «сом» при ПУСТОМ поле суммы теперь выбирает режим (как Пробел), окно остаётся открытым, фокус уходит в поле; при заполненном поле — применяет скидку.
