# Что нового в мобилке 1.18.24 (подготовлено, НЕ выложено)

Подготовлено 27.11.2026. Номер: 1.18.23+24 -> 1.18.24+25. Режим тестировщика только по коду (isTestBuild = false, как в 1.18.23). Подпись — ключ мобилки, ставится поверх 1.18.x, вход сохраняется.
Описание для GitHub на 5 языках: `NurMarketMobile/release-notes-mobile-1.18.24.md`.

## Для клиента

1. **Маркетплейс в телефоне.** Как в кассе: функции с иконкой, описанием и демо, тарифы. Видят владелец и администратор, кассиру раздел закрыт.
2. **Склад: поиск сканером и по фото.** Рядом с поиском по названию — «Сканер штрихкода» и «Поиск по фото» (умная камера). Найденный товар сразу в строке поиска.
3. **Чек по ссылке и QR.** QR на чеке ведёт на красивую страницу чека; «Отправить чек» шлёт ссылку и «Ваш чек №…». Без связи — чек без QR, как раньше.
4. **Сфера магазина с сервера.** Берётся из профиля компании (market_profile) при запуске, возврате в приложение и «потянуть для обновления» — сменили сферу в кассе, телефон подхватил без нового входа.
5. **Нур-советник.** Объясняет разделы и Маркетплейс, сам открывает нужный экран, только читает (ничего не меняет). Ответ виден по мере прихода, под ним «Использовано: …». Звонок начинает отвечать быстрее.
6. **Вход на тарифе «Мини».** Если место телефона занято — вопрос «Выйти там и войти здесь?» вместо «неверный пароль». Если у компании включено «Подтверждать PIN» — спрашивается PIN владельца/админа.
7. **Удобство и точность.** «0» в числовом поле стирается при вводе; дробные единицы (м, л, мл) не округляются (2,5 м × 50 = 125).

## Что не проверено вживую / риски

- Результаты проверки в эмуляторе — в отчёте агента подготовки; на настоящем телефоне не проверялось.
- Маркетплейс: включение/выключение функций идёт на сервер (PUT модулей) — нажимать только на тестовом аккаунте.
- Красивый чек зависит от сервера (share-link); на старом сервере QR просто не печатается.
