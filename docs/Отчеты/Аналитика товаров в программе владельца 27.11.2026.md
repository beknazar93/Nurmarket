# Аналитика товаров в программе владельца — 27.11.2026

Просьба владельца: «Аналитика товаров в десктоп тоже добавь! Общее количество товаров, категории, общее количество, заканчивается — короче подробнее».

## Где раздел
Программа владельца → **Отчёты → Аналитика → вкладка «Склад»** (раньше там были 5 плиток, топ-10 и категории). Тот же элемент (`WarehouseStockAnalyticsView`) стоит и во вкладке «Аналитика» окна склада кассы. Платная доп. функция «Аналитика склада» (Маркетплейс) — как и раньше; её карточка в Маркетплейсе (иконка 📊, описание на 5 языках) обновлена под новые возможности.

## Что в разделе
- Строка фильтров: поиск (единый `SearchMatch`: название, штрихкод, артикул, категория, бренд), список категорий («Все», по названию, «Без категории»), кнопка «Excel».
- Плитки: всего товаров (позиций); единиц на складе; стоимость по закупке (только при праве на закупку); стоимость по продаже; потенциальная наценка и % к закупке (только при праве); нет в наличии; заканчивается; в минусе; без цены; без штрихкода; без категории. Плитки считаются по фильтру.
- «По категориям (N)»: цветные полосы (общий `BarChartRenderer`, топ-10 по стоимости с долей) и таблица — категория, товаров, единиц, по закупке*, стоимость, заканчивается, нет в наличии, доля. Сортировка по клику на заголовок (по числу, не по тексту). Выбор строки раскрывает ниже список товаров категории (остаток, минимум, цена, стоимость).
- Списки «Заканчивается (N)» (остаток и минимум; самые критичные первыми) и «Нет в наличии (N)».
- «Топ-20 по стоимости остатка»: полосы (топ-10) и таблица (цена, закупка*, стоимость).
- Excel (`StockAnalyticsExport`, общий `ExcelWorkbookBuilder`): листы «Сводка», «Категории» (+ круговая диаграмма), «Заканчивается», «Нет в наличии», «Топ по стоимости» (+ столбчатая). Выгружается то, что на экране (фильтр написан в шапке файла). Закупка в файле — только при праве. Тот же тарифный замок, что у остальных выгрузок аналитики (`TariffGate.CanUseAnalyticsExport`).

## Что и как считается (один класс — `Infrastructure/Services/StockAnalytics.cs`)
Формулы те же, что у итогов «Склад → Товары» (`WarehouseWindow.RefreshWarehouseTotals`): позиции — все товары каталога; единицы — сумма остатков; стоимость — остаток × цена (закупка — `PurchasePrice`, продажа — `ParsePrice(PriceLine)`); «заканчивается» — `IsLowStock` при остатке > 0 (минимум карточки `MinQuantity`: остаток не выше минимума, иначе общий порог — остаток меньше 10); «нет в наличии» — остаток ≤ 0 (минус тоже); «в минусе» — `IsNegativeStock`. «Без штрихкода» не считает услуги и весовые товары с PLU. Деньги не округляются в расчёте, показ — `MoneyText`; в окнах нет `Math.Round/Floor` (check-money-in-views без новых нарушений). Без права на закупку закупочные поля в отчёте — `null` (не просто скрыты).
Данные — каталог кассы/программы (`CatalogCacheService.Products`), как в «Склад → Товары»; отдельных запросов к серверу нет.

## Чего нет и почему
- **Фильтр филиал/склад** — в каталоге кассы остаток один на компанию, разреза по филиалам в `CatalogProductTileVm` нет.
- **«Залежавшиеся»** — данных о последней продаже товара в каталоге нет (только локальная история продаж, у программы владельца она пуста) — не делал, как и было сказано.
- **«Заказать / в закупку»** — перехода «в закупку с выбранными товарами» в программе нет (есть вкладка рекомендаций в «Закупках» без передачи списка) — кнопку не добавлял.
- **PDF** — в `AnalyticsExportService` формат Excel/Word; для склада сделан Excel.
- `WarehouseWindow.RefreshWarehouseTotals` продолжает считать итоги своим кодом (файл занят параллельным исполнителем); формулы совпадают, расхождение ловит тест `SameFormulas_AsWarehouseTotals`. Позже имеет смысл переключить его на `StockAnalytics.Build`.
