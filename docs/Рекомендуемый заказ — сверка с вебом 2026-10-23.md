## 1. Формулы сервера (проверены по цифрам)

Обозначения: N — «Период анализа» (сервер принимает только 7, 14, 30; другое число — 400), C — «Запас до следующей закупки»
(целое 0…400, проверено 0, 1, 3, 4, 5, 7, 14, 60, 365, 400), S — «Страховой запас» (целое; дробное — 400).

| Что | Формула сервера | Проверка (NBS) |
|---|---|---|
| Продажи в день `sales.average_per_day` | продажи за N дней ÷ N, округление до 2 знаков | Aos: 328 ÷ 30 = 10,93 |
| Хватит на `stock_forecast.days_remaining` | остаток ÷ **неокруглённая** продажи в день, 2 знака; `null`, если продаж за период нет | 43 ÷ (328/30) = 3,93 |
| Рекомендация `recommended_quantity` | `ceil(продажи_в_день × (C + S) − остаток)`, если > 0, иначе 0. Штучный товар — целое вверх. Весовой — дробное (округление не выяснено, не было случая > 0) | 10,933 × 17 − 43 = 142,87 → 143; C=4,S=0 → 1; C=3,S=0 → 0 |
| `summary.estimated_total` | сумма `рекомендация × purchase_price` по товарам; `null`, если рекомендаций нет | 111 × 35 = 3885 |
| `summary.products_count / recommended_products_count / critical_products_count` | число товаров / рекомендация > 0 / статус `critical` | совпало на всех 10 поставщиках |
| Рост `sales.trend_percent` | (продажи периода − продажи прошлого такого же периода) ÷ прошлый × 100, 2 знака; `null`, если прошлого нет, а сейчас продажи есть («+ новые продажи»); 0, если обоих нет | (328 − 26) ÷ 26 = 1161,54 |
| Прошлый период `previous_period` | N дней перед последними N | видно при смене N |
| Продажи 7/14/30 дн. | `last_7_days / last_14_days / last_30_days` — всегда, независимо от N | — |
| Последняя закупка | `last_purchase{date, quantity, purchase_price}` или `null` | — |
| Статус `stock_forecast.status` | `ok` — хватает; **`low`** — хватит на меньше, чем C + S дней (то есть есть рекомендация); **`ending`** («скоро закончится») — порог **не зависит от настроек**, лежит между 4 и 12 днями (при C=0,S=0 и 3,93 дня — `ending`; 12,0 дня — `ok`); **`critical`** — товара нет (остаток 0; у NBS «тест весовых 1»: остаток 0, продаж в периоде 0, раньше были) | запросы p3/p4/p5 |
| Сортировка | сервер отдаёт в **своём порядке** (не по срочности и не по алфавиту; критичный товар NBS — 4-й из 6) | p6 |
| Фильтры/поиск | `only_needed`, `filter`, `status`, `search` сервер не знает (исследование 22.10) → фильтры и поиск сайта — в браузере | doc 22.10 |
| Страницы | `page`, `page_size`; `next` — ссылка на следующую | p6 |
| Упаковка `pack_size` | поле есть (у «Test optoviy» поставщика Шоро — 20), влияет ли на `recommended_quantity` — **не выяснено** (у этого товара нет продаж) | ТЗ 34 |
