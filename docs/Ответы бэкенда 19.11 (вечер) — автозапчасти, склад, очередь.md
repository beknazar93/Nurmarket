## Поля товара для автозапчастей (меняет §8 ТЗ «Автозапчасти»)
1. **Доп. штрихкод уникален в компании** — один каталожный номер у двух карточек сервер не примет («уже есть у товара …»). Кросс-номера и аналоги в `alternate_barcodes` НЕ класть.
2. **`attributes: [{key, value, unit?}]`** в создании и PATCH товара, отдаются в `products/list` и `products/{id}`: key — латиница/цифры/_ (с буквы, до 32), value — строка до 64 знаков или число, до 30 атрибутов, ключ один раз. Несколько кросс-номеров: `oem`, `cross_1`, `cross_2`… (или через запятую в одно значение до 64). **Ячейка — отдельное поле `storage_location`** (по филиалу, фильтр `?location_prefix=`). **Аналоги — `related_input: [id товаров]` → `related[]` в ответе (до 100).** Состояние — атрибут `condition` (new/used/refurb).
3. **Поиск:** `?search=` ищет и по значениям атрибутов (по вхождению); точный фильтр `?attr.oem=12345` (по индексу, через запятую — ИЛИ). Пробелы и дефисы сервер НЕ нормализует — хранить номер без них и так же чистить запрос на кассе.
→ §8 ТЗ можно делать на сервере, не только локально.

## Склад (К-4/К-5/К-8)
1. `GET api/main/settings/stock/` → negative_stock_policy, costing_method, batches, expired_sale_policy (allow|warn|block), reserved_sale_policy (warn|block) + списки допустимых. `GET api/main/stock/expiring/?days=30&page=&page_size=&product=` → {days, today, count, page, page_size, source, results[{batch_id, product_id, name, remaining, expires_at, days_left, expired, received_at, lot_no…}]}.
2. `reservation_ids` — на уровне чека: `pos/checkout/ {…, reservation_ids: [id]}`. Свои резервы не мешают продаже. Выбор резерва: `GET api/main/reservations/?product=&source=&source_id=&status=active` (по клиенту фильтра нет — по `source_id` заказа/отложенного чека).
3. 409 `{code: "insufficient_available", detail, available, reserved, quantity}` — поля верхнего уровня, числа строками. `allow_over=true` → 201 + warnings.
4. Настройки дней «скоро истекает» нет: в `stock/expiring/` по умолчанию days=30 (0–365), касса передаёт своё.
5. Прямой PATCH остатка (`products/{id}/`) срок и номер партии НЕ принимает — партия создаётся без срока по закупке карточки. Срок/lot_no — только строкой прихода (а приход сейчас всегда с поставщиком). Если нужно — добавят expires_at/lot_no к правке остатка (запросить).
