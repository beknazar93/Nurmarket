# ТЗ Умару: тариф «Мини» для Базара — только мобильное приложение, 500 сом/мес (22.11.2026)

Решение владельца 22.11.2026 (дословно): «тариф Мини для Базара без веба, десктопа, только мобилка! тариф за 500». Это уточняет ТЗ от 20.11 (`docs/ТЗ Мини-тариф 500 сом — телефон для мини-контейнеров (20.11.2026).md`): там сайт для «Мини» был вопросом владельцу — теперь ответ: **сайта тоже нет**. Цена 500 сом/мес и пробный 14 дней у «Мини» на сервере уже есть (ответ Умара 21.11). Нужно подтвердить и дожать ограничения.

## Что хотим
Продавец на базаре/в контейнере ставит наше мобильное приложение, регистрируется, платит 500 сом/мес и работает **только с телефона**: один сотрудник, одна касса, один телефон. С компьютерной кассы (Windows/Linux/Android-касса) и с сайта app.nurcrm.kg этот аккаунт войти не может. Сфера компании — «Базар» (профиль `bazaar`, розница; опт — `bazaar_wholesale`), её нельзя выбрать в мобилке самому: она приходит с сервера.
