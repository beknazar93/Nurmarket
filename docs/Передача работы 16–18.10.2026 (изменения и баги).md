## 1. Как продолжить

1. Прочитать [CLAUDE.md](../CLAUDE.md), [AI_HANDOFF.md](AI_HANDOFF.md), этот файл.
2. Сборки:
   - старая касса: `dotnet build NurMarketKassa.Avalonia/NurMarketKassa.Avalonia.csproj -c Debug` (из папки `NurMarketKassa.Avalonia`); выпуск — `dotnet publish … -c Release -r win-x64 --self-contained true -o dev-out`;
   - новый десктоп: из `NurMarketDesktop/NurMarket.Desktop` — `dotnet build -c Debug -p:OutputPath='bin\DevBuild5\'` (каждый раз новая папка `DevBuildN`, если прежний exe запущен);
   - телефон: `export PATH="/d/flutter/bin:$PATH"`, `cd NurMarketMobile`, `flutter analyze`, `flutter test` (тесты телефона безопасны, база не трогается);
   - стенды: `tools/stress/KassaStress` (`dotnet run -c Release`, `STRESS_ONLY=<часть названия раздела>`), `tools/stress/FunnelStress`.
3. Проверочные экземпляры нового десктопа (тестовый аккаунт, свои папки данных): касса — `NurMarket.Desktop.exe --qa-instance`, программа владельца — `--owner --qa-instance`; без окна на экране владельца — плюс `--qa-quiet`. Вход: `tools/qa/qa_login.ps1` (пароль только через переменную `QA_PASS` при запуске, нигде не хранить). Сейчас на ПК могут быть открыты видимые экземпляры (касса и владелец из `bin\DevBuild5`) — их можно закрыть.
4. Отладочные ключи (только Debug): `--qa-open=<раздел>`, `--qa-sales=export|esf|esf-receipt` (с `--qa-open=sales`), переменная `NURMARKET_QA_SAVE_DIR` — выгрузки сохраняются без окна «Сохранить как».
