## 5. Что осталось

1. **Касса на маленьком экране мелкая (п. 3 таблицы).** Масштаб кассы считается так, чтобы вид 1000×660 (компактный) влез целиком. На 1366×768 @150 % (911×464) это 67 %. Рекомендация клиентам с 15,6" 1366×768: масштаб Windows 100 % (физически кнопки остаются крупными), либо «Во весь экран» в Настройках → Экран (на 150 % даёт 74 % вместо 67 %). Вид «Классика» из всех видов лучше всего для маленьких сенсорных экранов. Переделка вёрстки под 900×460 — отдельная задача.
2. **Окна с системной рамкой уходят под панель задач** (п. 4 таблицы) — `DialogScreenFit.FitToKassaScreen` и `FitToScreen` должны вычитать высоту заголовка и рамки (`FrameSize − ClientSize`) у окон с `SystemDecorations.Full` без `ExtendClientAreaToDecorationsHint`. Файл в `Views.axaml/Dialogs` — передано агенту модалок.
3. «Настройки кассы»: «Сохранить» страницы весов и кнопки «Настроить по этикетке…/Все префиксы/Сбросить правила» только прокруткой даже на 1920×1080 — закрепить «Сохранить» внизу окна.
4. Склад: радиокнопки фильтров 36 по высоте и впритык (2 px); при 150 % кнопки строки «Изменить остаток / Изменить / Ещё» за правым краем таблицы (прокрутка вбок есть). Склад сейчас правит другой агент — не трогал.
5. Меню ☰ кассы (`SideMenuView`) — заголовки групп «Работа», «Информация и клиенты», «Система» 283×32 (нужно ≥ 44); «✕» 44×44 норма. Меню переделывает агент меню — не трогал.
6. Тёмная колонка владельца при высоте < 650 точек — подписи только в подсказке; кнопки групп 68×36 вплотную (1 px). Предложение: в режиме «только значки» добавить промежуток 4 px и высоту 44.

Не правил (вне главных экранов, риск конфликтов).
