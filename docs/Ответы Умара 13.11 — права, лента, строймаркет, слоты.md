# Ответы Умара 13.11.2026 (переслал владелец)

## 1. can_sell_below_cost
- Сервер владельцу и админу НЕ присылает true (поле null). Им можно всегда по роли.
- Правило кассы: можно, если роль owner/admin ИЛИ can_sell_below_cost === true. Проверка только когда скидка > 0.
- Отказ: 400 `{"code": "price_below_cost", "min_price": "…", "required_permission": "can_sell_below_cost", "unit_price": "<текст>"}`. В checkout и bulk ошибка идёт в строке, с `index`.

## 2. addons.source и лента событий
- source: `key` (ключ), `trial` (пробный период), `support` (включила поддержка), `promo` (промокод — в WhatsApp или на support.nurcrm.kg).
- Лента: `GET main/changes/?since=<курсор>&types=a,b&limit=500` (макс. 1000).
  - ответ `{"cursor", "has_more", "events": [...]}`; без since — текущий курсор и пустой список, отсчёт с этого момента;
  - событие `{"id", "type", "event", "at", "branch", "actor", "entity", "entity_id", "data"}`; type через подчёркивание (sale_paid, stock_changed), event — имя как в WebSocket;
  - типы: product_changed, stock_changed, client_changed, bonus_changed, staff_changed, cash_moved, debt_paid, debt_created, features_changed, receipt_changed, app_settings_changed, pos_request_changed, supplier_debt_changed, rental_* и прежние события вебхуков;
  - хранятся 7 дней; старый курсор — 400 `cursor_expired` (перечитать всё), испорченный — 400 `invalid_cursor`; есть ETag (304).

## 3. Электроника
Серийные номера и гарантия выложены (+sn1311), см. «Сервер 13.11 — серийные номера, гарантия, Электроника.md». Ремонт и trade-in на сервере отложены.

## 4. Строймаркет
- Упаковка для м² — единица продажи товара `sale_units`: `{"name": "Упаковка", "unit_code": "pack", "factor": 1.44, "barcode", "price", "wholesale_price"}`. factor — сколько базовых единиц (м²) в упаковке. В строке чека касса шлёт `sale_unit` и количество в упаковках; сервер списывает qty × factor.
- Цена прораба — уровень цен. У клиента `price_level`. Уровни: `GET main/price-levels/`. Цены товара по уровням: `GET main/products/<id>/prices/`. Расчёт цены для клиента: `POST main/price-levels/quote/ {client, items: [{product, qty}]}`. Объекты прораба: `GET/POST main/clients/<id>/objects/`.

## 5. Слоты устройств (на сервере с 06.11)
- Один вход на каждый тип устройства, сайт без ограничения.
- Место занято — 409 `device_slot_taken`; войти с заменой — `replace_device`. Старое устройство получит 401 `session_revoked`.
- Несколько касс одного типа на одном логине — флаги компании `allow_multi_desktop_pos`, `allow_multi_android_pos`.
- Касса Android должна слать `X-NurMarket-Client: android-pos/<версия>`.
