## Ошибки по важности

### КРИТИЧНО
Нет (денежных потерь не найдено: суммы возвратов и оплат долга верные, ошибки — в отображении и подтверждениях).

### ВАЖНО
- **Б1. В шапке кассы «Касса: …» неверная сумма после долговых операций.**
  Шаги: продажа «в долг» 2,00 с предоплатой 1,00 **безналом** → в шапке +1 наличными (1 040 → 1 041). Затем: продажа в долг 2,00 → «Оплата долга» 2,00 наличными (1 042 ✅) → полный возврат этого чека «Выдать покупателю: 2,00» → в шапке остаётся 1 042 (должно быть 1 040).
  Журнал `ShiftEvents` при этом верный: `cash=2.00` у возврата, `noncash=1.00;debt=1.00` у первого. Ошибка в пересчёте шапки после оплаты (предоплата безналом считается наличными) и после возврата долгового чека (наличные не вычитаются).
  Где смотреть: `MainWindow.axaml.cs` / `MainStatusViewModel` (остаток кассы после оплаты и возврата), `BasketPanelViewModel.cs` ~1736 (`CashReceivedForApi` для `debt` несёт всю предоплату, и при безнале тоже), `ReturnSaleDialog.axaml.cs` (обновление остатка после возврата). Проверка: две эти цепочки по 1–2 сома — шапка = наличные в ящике.
- **Б2. «Оплата долга» в кассе: кнопка «Оплатить» в строке чека принимает деньги сразу, без подтверждения и без выбора способа.** Аудит Клиент, 22.10 07:39: одно нажатие — «Оплачено 2,00 сом. Долг по чеку погашен». «Погасить» (одной суммой) спрашивает подтверждение, а строка — нет. `PayDebtDialog.axaml.cs` (обработчик кнопки строки). Проверка: «Оплатить» в строке → окно «Принять от … N сом (Наличные)? Останется …».
- **Б3. Ключи ИИ видны кассиру открытым текстом.** Настройки кассы → «Операции»: поля Gemini, Groq, OpenRouter показывают ключи целиком — любой кассир может их скопировать. Значения в отчёт не выписаны. Поля стоит маскировать («••••» + «Показать» по коду владельца) или вовсе убрать из кассы. `PosSettingsWindow` / вкладка «Операции» (`TelegramAiKeyBox`, `GroqKeyBox`, `OpenRouterKeyBox`).
- **Б4. Владелец → «Клиенты»: долг без продажи не виден.** «Аудит 22.10» → «＋ Записать долг без продажи» 1,00 → «Долг 1,00 сом записан…». После этого в карточке «Долг: нет — Клиент ничего не должен.», в списке «—», «Вам должны» 225 856,00 не изменилось — и после «Обновить» тоже. Касса этот долг видит (1,00, строка «Долг без продажи»). Список клиентов считает долг только по продажам. `ClientsWindow.Debt.cs`, `DebtsView.RefreshSharedExactAsync`, карточка клиента. Проверка: долг без продажи 1 сом → в списке 1,00, в карточке «Долг 1,00», «Вам должны» +1.

X-отчёт: «Возвраты 10,00», хотя выдано 4,00.** Сервер записывает возврат строки без доли скидки на чек (001849: 5,00 вместо 1,43 и 2,00 вместо 0,57) и долговой чек целиком (001850: 2,00, из них 1,00 — уменьшение долга).
