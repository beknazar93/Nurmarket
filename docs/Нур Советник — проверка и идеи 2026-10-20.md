## 1. Что умеет Нур Советник (по коду)

Файлы: `Views.axaml/Main/AiAdvisorWindow.cs` (окно, ~3900 строк), `Infrastructure/Services/TelegramAiChat.cs` (запросы к ИИ, инструкции), `Services/OwnerAiContext.cs` (сводка магазина для ИИ), `Infrastructure/Services/ProductActionPlan.cs` (действия с товарами), `Infrastructure/Services/AiProviders.cs` (Groq/OpenRouter), `Services/OwnerSalesData.cs` (чеки за период), `Infrastructure/Services/Hardware/GeminiLiveVoice.cs` (звонок).

| Возможность | Как сделано |
|---|---|
| Вопросы по магазину | В ИИ уходит «сводка»: карточки «Сводки» (выручка/чеки/прибыль за выбранный период, выручка по дням за 7 дн., лучшие товары), бот, допродажа, долги клиентов и поставщиков, должники под кодами [Д1]…, анализ товаров (не продаются, закончились, мало осталось, затоварено, падают, низкая наценка, растут, клиенты, заказы бота), ABC за 30 дней, весь склад (до 600 товаров с закупкой и остатком), остатки, сроки годности |
| Сотрудники, зарплата, табель, Z-архив | Только если в вопросе слова «зарплат/сотрудник/смен/табел/касс/отчёт…» — программа сама грузит с сервера список, зарплату (как на сайте), табель и архив смен |
| Чеки за день/период | «чек…» или «продажи + список/таблица» → программа грузит чеки (до 60 строк) и итоги, ИИ показывает таблицей |
| Таблицы | Ответ в Markdown-таблице рисуется настоящей таблицей (`RenderTables/BuildTable`) |
| «открой …» | Короткая команда (≤ 6 слов) — открывает раздел/товар сразу, без ИИ; ИИ тоже может предложить `open_section`, но выполняется только если владелец сам сказал «открой» |
| Изменение товаров | ИИ пишет служебные строки `ТОВАР: {…}` (приход, списание, пересчёт, цена, закупка, срок, описание, страна, бренд, категория, штрихкод, артикул, новый товар) → карточка «Изменить товары?» с кнопкой «Выполнить». Без нажатия ничего не меняется. Защита от двойного выполнения (подпись плана), минимальная наценка 20 % на приход, цена прихода не снижает текущую |
| Накладная по фото/PDF | Несколько страниц в одном вопросе; без подписи — спрашивает «накладная или описать товар?»; таблица строк + итоги; приход проводится **закупкой у поставщика** через окно «Провести закупку…» (не напрямую на склад), подсказка поставщика по накладной |
| Фото товара из интернета | Без ИИ: поиск по названию (Яндекс.Картинки/открытые базы), варианты пронумерованы, «поставь фото 4»; список товаров без фото — из локального каталога |
| Поиск в интернете | Только по прямой просьбе («найди в интернете…»): Gemini google_search, у бесплатного ключа — через Groq (`browser_search`), источники ссылками |
| Голос | 🎤 — вопрос голосом, ответ коротко и вслух (Gemini TTS); «Разговор» — живой звонок Gemini Live (`gemini-3.1-flash-live-preview`), в звонке — те же разделы/товары/фото, таблицы — в чат |
| Языки | Отвечает на языке вопроса (ru/ky/en/tr/uz), имя «Нур Советник / Нур Кеңешчи», есть кыргызские команды («ач», «кир»…) |
| Должники и WhatsApp | Таблица должников, «напомни должникам» → кнопки «Написать в WhatsApp» с готовым текстом (отправляет владелец) |
| Telegram-бот | Включить/выключить функции бота (строка `БОТ: {…}` → кнопка «Применить»), свои сценарии/команды бота (`СЦЕНАРИЙ: {…}`), в самом боте — тот же ИИ для владельца (подтверждение «да/нет» или кнопки, 15 мин) и ИИ-консультант для покупателей (только каталог) |
| Сайт | «поставь тему Ала-Тоо», «опубликуй сайт» — программа сама в «Редакторе сайта» |
| История | `%APPDATA%\NurMarketOwner\ai-chats.json`, 30 последних разговоров, отдельно для каждой компании (AccountDataIsolation), удаление ✕ |

**Провайдеры ИИ.** Основной — Google Gemini (по очереди `gemini-3.5-flash-lite`, `flash-lite-latest`, `3.1-flash-lite`, `flash-latest`, `3.5-flash`, запоминает рабочую). Запасные, если Gemini не ответил: OpenRouter (`openrouter/free`, полная сводка до 120 тыс. символов), затем Groq (`gpt-oss-120b`, сводка до 9 тыс.). Поиск в интернете — Groq. Ключи — в личных «secrets» настроек NurCRM.

**Лимиты.** Таймаут Gemini 45 с, Groq-поиск 30 с; при 429 поиск выключается на 30 мин; ответ до 1200 токенов (накладная — 32 768); память разговора 8 пар реплик; ИИ только на тарифе выше «Старт» (`TariffGate.CanUseAi`); раздел открывается по праву «Аналитика».

**Журнал.** `ИИ-советник: сводка N мс, ответ ИИ N мс`, ошибки частей сводки, «действия выполнены по подтверждению владельца (N)».

**Что уходит во внешний ИИ.** Имена и телефоны **клиентов-должников не уходят** (коды [Д1], подстановка на этом ПК — `RevealDebtors`) — хорошо. Уходят: суммы, весь склад с закупочными ценами, ABC, выручка; **имена сотрудников, их ставки, начисленная зарплата и табель** (при вопросах о сотрудниках); имена кассиров в таблице чеков; фото накладных (реквизиты поставщика). При сбое Gemini — та же сводка в **OpenRouter `openrouter/free`** (бесплатные модели разных компаний, условия хранения данных неизвестны). Предупреждение у поля ключа говорит только про Google.

## 4. Ошибки

### КРИТИЧНО

**1. Сводка магазина обрезается до 16 000 символов — склад, ABC и часть анализа до ИИ не доходят.** ✅ **исправлено 21.10** (см. `redesign-progress.md` «Нур Советник — исправления и новое»).
`TelegramAiChat.AskCoreAsync` → `ClampPromptContext(system, 16000)` (добавлено в 1.17.58). В `system` сначала инструкции: `OwnerAppPrompt` ≈ 5 600 симв. + `ProductActionPlan.PromptText` ≈ 3 000 + карточки вопроса (сотрудники/чеки — ещё несколько тысяч), и только потом «СВОДКА МАГАЗИНА». Для NBS один склад — ≈ 19 300 символов (330 товаров, посчитано по копии базы), ABC — ещё тысячи. Остаётся ~7 000 символов: «Сводка», бот, долги, должники, начало анализа. Склад, ABC, остатки (`BuildLowStock`), сроки годности, «Склад: N позиций по закупке» **отрезаны**, а инструкция при этом говорит ИИ «в сводке есть склад и ABC». При вопросе про сотрудников или чеки обрезается ещё больше (карточки стоят перед сводкой). Голосовой звонок (`BuildOwnerVoiceInstruction`) не обрезается — **звонок знает больше, чем чат**.
Шаги: спросить «Сколько всего товаров на складе и на какую сумму по закупке?» или «Какие товары группы A по прибыли?» → ожидаемо «нет данных» или выдуманная цифра (эталон: 330 товаров, в наличии 319, закупка ≈ 20,97 млн сом по локальной копии).
Решение: обрезать не всю строку, а части сводки по важности (склад — только нужные товары по вопросу и итоги; ABC — топ-10 групп), лимит поднять (Gemini принимает 1 млн токенов), инструкции — короче.

**2. Долги в советнике (и в Telegram-боте) — по «быстрому» списку, не по точному, как «Сводка».** ✅ **исправлено 21.10** (см. `redesign-progress.md` «Нур Советник — исправления и новое»).
`OwnerAiContext.BuildDebtTotalsAsync`/`BuildDebtorsPseudonymousAsync` берут `debt_amount ?? total` из `PosDebtSalesAsync`, без `debt_remaining` и без уточнения по сделкам. 20.10 то же самое уже исправляли для «Сводки» и «Клиентов» (`DebtsWindow.cs`: «Сводка ≈ 245 858 против точных 225 858, Проверочный 137 811 вместо 117 811» — быстрый список не вычитал оплаты), а советник и бот (`TelegramBotPollingService.cs` 686/820) остались на старом расчёте.
Шаги: «Кто должен больше всех и сколько всего нам должны?» → ожидаемо ≈ 245 856 / Проверочный 137 811 вместо 225 856 / 117 811 (живьём не подтверждено — см. раздел 0).
Решение: брать `DebtsWindow.KnownExact()/LoadExactDebtorsAsync`, общий источник с «Сводкой».
