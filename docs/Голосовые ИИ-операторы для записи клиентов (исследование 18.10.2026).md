# Голосовые ИИ-операторы для записи клиентов по телефону: обзор для NurMarket (на 18.10.2026)

_Исследование по просьбе владельца: «голосовые AI операторы на звонки для записи клиентов — изучи этот вопрос», плюс callagentai.com и mychatbot.app/ru/voice-ai. Пометка **[не проверено]** — первоисточник не найден. Цены примерные, без НДС и без стоимости связи, если не сказано иное._

## Рекомендация

1. **Глобальная платформа — ElevenLabs Agents.** Единственная крупная платформа, где подтверждены и распознавание кыргызской речи, и кыргызский голос:
   - распознавание Scribe v2 поддерживает `kir`, качество «Good» (WER 10–20 % на чтении FLEURS);
   - кыргызский голос — в моделях Eleven v3, v3 Conversational, v4 и v4 Turbo (v4 Turbo рекомендована для агентов);
   - агент во время разговора обращается к нашему REST API (webhook-инструменты), есть SIP-транк и API для создания агентов;
   - около **$0,08/мин** плюс LLM.
   - Запасной вариант с теми же кыргызскими компонентами — **Vapi** (около $0,13–0,20/мин в сумме).
2. **Русскоязычный рынок — Yandex AI Studio, голосовые агенты (Realtime API).** Самый дешёвый: около $0,02–0,04/мин; вызов функций, MCP и SIP. **Кыргызского нет** (кроме русского — казахский и узбекский). Данные уходят в Россию.
3. **Начинать с русского языка.** Кыргызский — отдельный пилот на реальных звонках. Обязательна передача звонка живому сотруднику.
4. **Телефония:** бишкекский номер у Zadarma ($4–8 в месяц) или у местной облачной АТС, плюс переадресация с мобильного. К ИИ-платформе, скорее всего, нужен SIP-мост (Asterisk, LiveKit SIP или Voximplant): платформы требуют TLS-транк.
5. **CallAgentAI.com и MyChatBot Voice AI для MVP не рекомендуются** (разделы 2 и 3).
6. **Ориентир за 100 звонков по 2 минуты (200 минут):** ElevenLabs ≈ $18–25; Vapi ≈ $26–40; Yandex ≈ $4–8; свой стек ≈ $6–20 плюс серверы и разработка. К каждому — номер ($4–8 в месяц) и переадресация у оператора.

## 5. Кыргызский язык: реальное качество

- Лучший облачный вариант — ElevenLabs (Scribe WER 10–20 % на FLEURS + голос v3/v4). На телефонном звуке 8 кГц с шумом и смешением языков будет хуже — нужен свой тест на 50–100 записях.
- Google Chirp 3 `ky-KG` (Preview) — альтернативный распознаватель через Vapi или свой стек.
- Нет кыргызского: OpenAI (Whisper, gpt-4o-transcribe, gpt-realtime), Azure, Yandex, Deepgram, Retell, Sber (не найдено).
- Открытые модели: kstu-asr (MMS-1B; WER 12,9 % FLEURS, 16,2 % разговорная; **только для исследований**); BuzzASR (Whisper-large-v3; WER ≈ 43 %); MMS TTS `kir` (CC-BY-NC, **некоммерческая**); Kani TTS 400m-ky (Apache-2.0).
- Смешанная русско-кыргызская речь: нужны автоопределение языка и повтор ключевых данных (имя, время, услуга) вслух.

## 6. Право КР (не юридическая консультация)

- **Цифровой кодекс КР** (принят 18.06.2025, подписан 31.07.2025, в силе ≈ с февраля 2026), гл. 11 — персональные данные. Проект порядка трансграничной передачи: список стран с «адекватной защитой», в остальные — с **согласия субъекта**; американские и российские платформы — трансграничная передача. Поправки о штрафах — первое чтение, май 2026. Требования к ИИ высокого риска (декабрь 2025); бот записи, вероятно, не высокого риска **[не проверено]**.
- Прямой нормы об обязательном предупреждении о записи звонка или о роботе **не найдено**; статус закона «Об информации персонального характера» (2008) не проверен.
- Практика: в приветствии на двух языках «Вам отвечает виртуальный помощник, разговор записывается»; возможность перейти на сотрудника; политика обработки данных на сайте; хранение записей 30–90 дней; договор обработки данных (DPA) с поставщиком, по возможности хранение в ЕС; голос не использовать как биометрию.
- Исходящие — только напоминания уже записанным клиентам, без «холодных» обзвонов.

## 7. MVP для NurMarket

**Ход звонка:**
1. Клиент звонит на номер 0312 или на мобильный с переадресацией.
2. SIP-провайдер → мост → ИИ-платформа; агент на каждую точку (название, услуги, часы, язык, номер звонящего как переменная).
3. Инструменты NurCRM: `get_business_info`; `find_client(phone)`; `get_services`; `get_masters(service_id)`; `get_free_slots(service_id, master_id?, date_from, date_to)` — 3–5 вариантов со `slot_id`; `hold_slot(slot_id)` — бронь на 5 минут; `create_booking(hold_id, name, phone, comment)` → `booking_id`; `find_bookings(phone)`, `cancel_booking`, `reschedule_booking`.
4. Перевод на человека (`transfer`); не ответили — задача «перезвонить».
5. Webhook после звонка → воронка CRM; подтверждение по SMS или WhatsApp и напоминание накануне.

**Что нужно от бэкенда NurCRM:**
- REST-методы из п. 3; время ISO 8601 с поясом Asia/Bishkek; телефоны +996.
- `POST /voice/calls` (после звонка): call_id, номера, длительность, язык, стенограмма, краткое содержание, ссылка на запись, итог, booking_id, стоимость → лид и этап воронки («ИИ: записан / не записан / перезвонить»).
- Ключ API на точку, подпись webhook (HMAC), ключ идемпотентности при создании записи.
- **Блокировка слота на сервере** (уникальность мастер+время, транзакция), брони с ограниченным сроком, проверка часов работы и длительности услуги на сервере.
- Источник `voice_ai` и `call_id` у записи; в десктопе и Android — значок «ИИ», стенограмма, задачи «перезвонить».
- Подключение по точкам: создание агента через API платформы, связь номера с точкой, вкл/выкл, месячный лимит минут.

**Стоимость 200 минут в месяц:** ElevenLabs ≈ $16 + LLM $2–6 + подписка (от ~$6, сторонние данные) + номер; Vapi $26–40; Yandex $4–8; OpenAI mini напрямую $4–16 + мост.

**Свой стек** (LiveKit Agents или Pipecat + LiveKit SIP или Asterisk + Scribe/Chirp/gpt-4o-transcribe + LLM с вызовом функций + синтез ElevenLabs, Yandex или NineNineSix): ≈ $0,03–0,10/мин, полный контроль, данные можно держать в КР; минусы — 1–2 месяца разработки, настройка задержки (конец реплики, перебивание), дежурство 24/7, мониторинг, лицензии кыргызских моделей.

**Порядок:** сначала ElevenLabs или Vapi; свой стек — когда станет много минут.

## 8. Риски и защита

| Риск | Чем закрыть |
|---|---|
| Агент «записал», а записи нет | «Записал» — только при успешном `booking_id`; повтор вслух; SMS-подтверждение |
| Двойная запись | Бронь слота, блокировка на сервере, идемпотентность; время только через `slot_id` |
| Шум, 8 кГц, акценты, смешение языков | Подсказки распознавателю (услуги, мастера), повтор данных, номер звонящего вместо диктовки, перевод на человека после 2 непониманий |
| Расходы | Лимит длительности (~5 мин), выход по тишине, лимит минут в месяц и одновременных звонков, оповещения |
| Злоупотребления | Лимит записей с номера в день, чёрный список, подтверждение по SMS, проверки на сервере, а не в промпте |
| Сбой платформы | Переадресация «нет ответа» на живой номер или автоответчик |
| Данные и законы | Предупреждение и согласие в приветствии, договор обработки данных, срок хранения записей |

## 9. Что не удалось проверить

- Регистрация и оплата картой из КР в ElevenLabs, Vapi, Retell (санкции касаются отдельных банков: Керемет — США и Великобритания; Капитал Банк — Великобритания и Канада; Толубай и Евразийский сберегательный — ЕС).
- Качество кыргызского на реальных звонках; задержка ответа (оценка 0,5–1,5 с).
- Номера КР у Twilio, Telnyx, DIDWW, Voximplant; стоимость переадресации Zadarma на внешний SIP; цены SIP-транков Beeline, MegaCom, O!.
- Явные нормы КР о записи звонков и роботах.
- MyChatBot: кыргызский и вызов нашего API во время звонка; CallAgentAI: полный список языков.
- Доступность для компаний из КР: Sber, T-Bank, МТС, Mango, Neuro.net, Zvonobot.
