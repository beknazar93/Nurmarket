## Ответы на вопросы раздела 11

1. **Что отвечает серверный бот при `consultant_enabled=true`.** ИИ (Gemini магазина) отвечает по каталогу и оформляет заказ служебной строкой `ЗАКАЗ: {...}`. Function calling пока нет. Нашли и исправили ошибку: с 12.11 у ИИ на сервере не было каталога и истории диалога (пропали константы в коде). Теперь каталог снова есть у всех магазинов.
2. **Схема «цену решает движок, токен оферты, закрытые поля `bargain_*`»** принята как есть. Делаем в Ф2.
3. **Пол цены в товаре.** Да: поля будут только в закрытых сериализаторах, тест на публичный API витрины добавим в Ф2.
4. **Handoff для Telegram** сделан, на базе ящика «Чаты» (см. ниже).
5. **Модель.** Хватает `gemini-3.5-flash-lite`: ответ 1–3 с.
6. **Признаки** назвали как в ТЗ: `bot_seller`, `bot_handoff`, `bot_sales_stats`. Они есть в `users/capabilities/` → `features` и в `telegram-bot/capabilities/`. Модуль Маркетплейса `bot_seller` — после Ф2.

## Решения владельца (уже заложены)

- Живой продавец — **владелец в Telegram** (чат владельца бота). Часы задаются в настройках, по умолчанию 09:00–20:00.
- Порог подтверждения человеком: **30 000 сом**, настраивается.
- Торг (Ф2): лимит скидки 5 %, маржа не ниже 10 %, только по отмеченным товарам. Сейчас настройки только хранятся, на ответы бота они не влияют.
- Ф3: только резерв на 24 ч без предоплаты.

## 1. Настройки — `GET/PATCH api/main/telegram-bot/settings/`, поле `seller_config`

PATCH частичный: можно прислать одно поле, остальные не меняются. GET всегда отдаёт полный набор с умолчаниями.

```json
"seller_config": {
  "seller_enabled": false,          // главный выключатель; false — бот работает как раньше
  "orders_enabled": true,           // ИИ оформляет заказы
  "tone": "friendly",               // official | friendly | short
  "greeting": "",                   // своё приветствие на /start (до 500)
  "signature": "",                  // подпись в первом ответе (до 100)
  "forbidden_words": [],            // до 30 слов, вырезаются из ответов
  "language": "auto",               // auto | ru | ky
  "handoff_enabled": true,          // кнопка «👤 Продавец» и передача владельцу
  "human_hours": {"from": "09:00", "to": "20:00"},  // {} — круглосуточно; по дням: {"mon": {"from","to"}, ..., "sun": null}
  "off_hours_reply": "",            // свой текст вне часов, {when} → «завтра с 09:00»
  "handoff_return_minutes": 120,    // 10…1440: тишина продавца → диалог снова у бота
  "confirm_threshold": 30000,       // заказ от суммы → карточка «Крупный заказ — подтвердите»; 0 — выкл.
  "knowledge": {"rules": "", "delivery": "", "payment": "", "work_hours": ""},  // rules до 2000, остальные до 500
  "bargain": {"enabled": false, "max_discount_percent": 5, "min_margin_percent": 10, "only_marked": true}  // Ф2, пока не действует
}
```
Ошибка: `400 {"seller_config": ["tone: official, friendly или short"]}`.

## 2. Как работает передача продавцу (в Telegram, без программы)

- Покупатель жмёт «👤 Продавец» или пишет «позовите продавца / оператор / менеджер / сатуучу…», либо ИИ сам решает «не знаю / клиент недоволен / просит человека».
- **В часы продавца** владельцу приходит карточка: имя, телефон (если клиент привязан), вопрос, последние сообщения. Под ней кнопки **«✋ Взять диалог»** и **«🤖 Вернуть боту»**. Покупателю бот пишет: «Позвал продавца…».
  - Пока диалог у продавца, бот молчит, а каждое сообщение покупателя (текст, фото, голос) пересылается владельцу.
  - Владелец отвечает через **«Ответить» (Reply)** на карточку или на пересланное сообщение. Ответ уходит покупателю от имени магазина, владелец видит 👍. Фото и голос тоже пересылаются.
  - Через `handoff_return_minutes` тишины диалог сам возвращается боту.
  - В ящике «Чаты» диалог помечен «нужен человек», ответы продавца там тоже видны.
- **Вне часов** бот отвечает: «Продавец ответит завтра с 09:00, оставьте номер…». Когда покупатель пришлёт номер, владельцу придёт «📞 Перезвонить: имя — телефон».
- Нажимать кнопки и отвечать может только владелец (`owner_user_id` / чат владельца).

## 3. Диалоги — для окна «Диалоги бота»

`GET api/main/telegram-bot/dialogs/?status=&from=YYYY-MM-DD&to=YYYY-MM-DD&page=&page_size=`
- `status`: `bot` | `needs_human` (ждёт продавца) | `human` (у продавца) | `callback` (перезвонить, живёт 3 дня). По умолчанию все.
- Период по последней активности, по умолчанию 30 дней.
```json
{"count": 3, "next": null, "previous": null, "results": [
  {"chat_id": "770013812", "name": "Айбек", "username": "", "client_id": null,
   "messages_count": 4, "orders_count": 0, "last_at": "...", "last_text": "хочу поговорить с менеджером",
   "status": "callback",
   "handoff": {"id": "...", "reason": "human", "status": "callback", "question": "...", "phone": "0555123456",
               "note": "...", "taken_by": "", "created_at": "...", "taken_at": null, "first_answer_at": null,
               "until": null, "closed_at": null, "order": null}}
]}
```
`reason`: `human` | `unknown` | `angry` | `big_order`. `handoff.status`: `waiting` | `taken` | `returned` | `expired` | `callback`.

`GET api/main/telegram-bot/dialogs/<chat_id>/` — переписка (последние 200: `at, text, reply, is_voice, order_number`), `handoffs[]`, `orders[]` (`id, number, total, status, created_at`).

`POST api/main/telegram-bot/dialogs/<chat_id>/` `{"action": "take"}` или `{"action": "return"}` — взять диалог или вернуть боту из программы (права как на настройки бота). Ответ: `{"status": "human"|"bot", "changed": true, "handoff": {...}}`. При `return` закрываются и заявки «перезвонить».

Ответить покупателю из программы можно уже сейчас через ящик «Чаты» (`api/main/inbox/conversations/<id>/messages/`). После ответа бот молчит на время паузы.

```json

 "dialogs": 3, "messages": 6, "people": 3,
 "orders": {"count": 0, "total": "0.00", "done": 0, "done_total": "0.00", "canceled": 0, "avg_check": "0.00"},
 "conversion_percent": 0.0,
 "funnel": {"dialogs": 3, "handoffs": 2, "orders": 0, "done": 0},
 "handoffs": {"total": 2, "by_reason": {"human": 2}, "callbacks": 1, "answered": 1, "unanswered": 0,
              "waiting_now": 0, "avg_answer_seconds": 40, "median_answer_seconds": 35},
 "unknown_questions": [{"at": "...", "chat_id": "...", "text": "Доставляете в Ош?"}]}
```
- Заказы бота — это `ShowcaseOrder` с `source` `telegram` или `telegram_bot`.
- `unknown_questions` — вопросы, на которые бот ответил «не знаю». По ним владелец пополняет «Правила магазина».

## 5. «Проверить бота» — `POST api/main/telegram-bot/test-ai/` `{"question": "...", "as": "customer"}`

Отвечает тем же промптом, что видит покупатель. Заказ не создаётся, продавец не зовётся.
```json
{"ok": true, "answer": "...", "model": "gemini-3.5-flash-lite", "functions_called": [],
 "handoff": "human" | null, "order_draft": {...} | null, "catalog_matches": ["<product_id>", ...]}
```
Без `as` — как раньше (вопрос владельца).
