## 2. Модель данных

```

  id, company, branch, number, client (или name+phone для гостя), resource, starts_at, ends_at,

  status: booked | confirmed | arrived | done | sold | no_show | cancelled,
  source: pos | owner | mobile | showcase | bot, comment,

  public_token (22 симв., для ссылки отмены), reminder_sent{h24, h2}, version, created_by

```

## 3. Правила сервера

1. **Пересечения**: на один ресурс в одно время — одна запись (с учётом `buffer_min`). Проверка — в транзакции с блокировкой ресурса на дату (гонка «две кассы / витрина + касса» → вторая 409 `slot_taken`). Двойная запись разрешена только флагом `allow_overlap` (администратор, сознательно).
2. **Свободные слоты** = расписание − исключения − записи − буферы, шаг `slot_step_min`, часовой пояс компании; «любой мастер» — объединение.
3. **Деньги**:
   - Предоплата — обычная продажа (услуга-аванс «Предоплата по записи №N», способ оплаты любой; онлайн — через QR, см. ТЗ автоподтверждения), ссылка `prepay_sale`.
   - «Продать» — касса формирует чек из `items` (цены — сервер, акции и уровень — как обычно) и шлёт `pos/checkout/` с `booking: id`; сервер **засчитывает предоплату** (уменьшает сумму к оплате на `prepay`, строка «Зачтена предоплата»), ставит `sold`. Повтор — тот же ключ (И-4); вторая продажа по той же записи → 409 `booking_already_sold`.
   - Отмена с предоплатой: раньше `cancel_free_until_hours` — возврат предоплаты (возврат продажи предоплаты); позже / «не пришёл» — по `no_show_policy`: `keep` (предоплата остаётся доходом) | `refund` | `credit` (на бонусы/депозит клиента). Деньги никогда не «теряются» молча: всегда документ возврата или доход с отметкой.
4. **Неявка**: через 30 мин после начала без «Пришёл» — подсказка администратору; `no_show` ставит человек (или авто через 2 ч, настройка). Счётчик неявок клиента; после 3 — онлайн-запись только с предоплатой.
5. **Напоминания**: задача раз в 5 мин, `telegram-bot/outbox/` kind `booking_reminder` (+ SMS после ТЗ SMS), одно на интервал (ключ `(booking, kind)`), по согласию `service`.
6. **Онлайн-запись**: публичный метод без авторизации; подтверждение телефона (код в бот/SMS), лимиты 5 запросов/мин с IP, 3 активных онлайн-записи на телефон; ответы без чужих данных (только «занято/свободно»).
7. **Офлайн-касса**: видит последний загруженный день, может создать запись локально со статусом «не подтверждена сервером» и отправить при связи (409 `slot_taken` → касса просит выбрать другое время). Продажа из записи офлайн — обычный офлайн-чек с `booking`.

## 5. Ошибки

409 `slot_taken {nearest[]}`, 409 `outside_schedule`, 409 `booking_version_conflict` (правили одновременно), 409 `booking_already_sold`, 409 `booking_cancelled`, 400 `online_lead_time {min_minutes}`, 429 `too_many_bookings`, 403 `otp_invalid`.

## 6. Признаки, права, модуль

- Признаки: `booking` (запись в кассе/мобилке/программе владельца), `booking_online` (витрина), `booking_prepay`.
- Права: `can_manage_bookings`, `can_edit_schedule`; мастер видит только свои записи (`can_view_own_bookings`).
- Модуль «Запись» — цена решает владелец (предложение 200 сом/мес, онлайн-запись +100); профили «Услуги», «Салон», «СТО».

## 7. Тесты приёмки

1. Мастер 10:00–19:00, перерыв 13–14, стрижка 45 мин + буфер 15, шаг 15, пустой день → начала 10:00, 10:15 … 12:00, затем 14:00 … 18:00; 12:15 и 12:30 нет (наезд на перерыв), 18:15 нет (после конца дня).
2. Две кассы записывают на 10:00 одновременно → одна 201, вторая 409 `slot_taken` с ближайшими.
3. Предоплата 300 → «Продать» чек 900 → к оплате 600, строка «Зачтена предоплата −300»; повтор продажи → 409 `booking_already_sold`.
4. Отмена за 5 ч (бесплатно до 3 ч) → возврат продажи предоплаты 300; отмена за 1 ч при `keep` → предоплата остаётся доходом, запись `cancelled`.
5. Напоминание за 24 ч уходит один раз, повторный проход задачи — не дублирует.
6. Онлайн-запись без кода → 403; 4-я активная запись на один телефон → 429.
7. Офлайн: запись создана локально на занятое время → при связи 409, касса показывает «выберите другое время».
8. Акция −20 % на услуги в среду → применяется в чеке из записи (общий расчёт).

## 8. Этапы

- **Ф1**: ресурсы и расписание, услуги с длительностью, записи (касса/мобилка/программа владельца), пересечения, «Продать» с засчётом предоплаты, напоминания в Telegram, отчёт загрузки.
- **Ф2**: онлайн-запись на витрине с OTP, отмена/перенос по ссылке, политика неявок, SMS-напоминания (после ТЗ SMS), почасовая аренда мест.

## 9. Что подхватит касса

- окно «Запись» (день/неделя по ресурсам, карточка, статусы, «Продать» → чек с услугами и консультантом), кэш дня для офлайна — 5 языков, чек-лист полей;
- `booking` в теле продажи и строка «Зачтена предоплата» в окне оплаты и на чеке;
- мобилка — та же запись (отдельная задача мобилки);
- программа владельца: расписание мастеров, настройки онлайн-записи, отчёт.
