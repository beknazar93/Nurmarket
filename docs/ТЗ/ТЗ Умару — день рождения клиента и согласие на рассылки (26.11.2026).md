# ТЗ Умару — день рождения клиента и согласие на рассылки (26.11.2026)

Касса и программа владельца: раздел «Клиенты → Рассылка» (отчёт о конкурентах 26.11, ТОП-15 п. 2). Сегменты: должники, «давно не покупали», VIP по сумме покупок, день рождения, все с телефоном. Отправки нет: программа открывает чаты WhatsApp по одному (wa.me с готовым текстом), «Отправить» нажимает владелец. Всё работает на текущих методах сервера; ниже — что улучшит.

## Что касса берёт сейчас
- Клиенты: `GET main/clients/` (`id`, `full_name`, `phone`); долги — существующая сводка долгов; покупки — `GET main/pos/sales/` за 365 дней (последняя покупка и сумма клиента считаются на кассе).
- Согласие: перед каждым открытием чата один запрос `GET main/clients/{id}/consents/` (3 с). Для рассылки отказом считается `marketing=false` при заполненном `updated_at`; для напоминания о долге — как у кнопки «WA» (оба согласия выключены с датой). Нет ответа — не отказ.
- «Не беспокоить» (отписка по просьбе клиента) хранится на кассе локально, в файле `client-mailing.json`.
- День рождения: если сервер присылает `birth_date` / `birthday` / `date_of_birth` в карточке клиента — касса его использует; иначе владелец вводит дд.мм в окне рассылки (локально).

## Что нужно от сервера
1. Поле `birth_date` (дата, необязательное) в карточке клиента: принимать в `POST/PATCH main/clients/`, отдавать в списке и карточке. Год можно не требовать (допустим `0000-MM-DD` или отдельное `birth_day`/`birth_month`).
2. Серверный признак «не беспокоить» в согласиях (`consents.do_not_disturb` или `consents.marketing=false` + источник `whatsapp_stop`), чтобы отписка действовала на всех кассах и в боте, а не на одном компьютере.
3. Сводка по клиенту одним запросом: `last_purchase_at`, `purchases_total` за период (`GET main/clients/?with_stats=1&since=…`), чтобы касса не листала чеки за год (сейчас до 40 страниц по 500).
4. Журнал рассылок на сервере (кому, когда, сегмент, кто нажал) — для общего ограничения «не чаще раза в N дней» между кассами. Пока ограничение действует на одном компьютере.

## Правила, которые касса соблюдает сама (для справки)
- Автоотправки нет; чат открывается только по нажатию владельца, по одному.
- Один клиент — не чаще раза в N дней (по умолчанию 14), не больше N чатов в день (по умолчанию 30), один номер — один раз, тихие часы 21:00–09:00, отказ клиента проверяется перед каждым чатом.
- В журнал и в файлы попадают только первые 4 цифры телефона; в текст подставляются данные только этого клиента.
