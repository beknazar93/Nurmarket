# Бот-продавец, этап 2: торг — что готово на сервере (26.11.2026, `+bot2711`)

Работает по разделу 3 ТЗ. Цену решает сервер, ИИ только разговаривает. Нижнюю границу цены («пол») ИИ и покупатель не видят никогда.

## Как работает

1. Покупатель пишет «дорого», «скидку сделаете?», «отдадите за 500 000?». ИИ не называет цену сам, он передаёт запрос движку.
2. Движок считает пол: **max(минимальная цена товара, закупка × (1 + маржа), цена × (1 − лимит скидки))**. По умолчанию лимит 5 %, маржа 10 %.
3. Решение движка:
   - предложение покупателя не ниже пола — **«Договорились»** по цене покупателя;
   - ниже пола — **встречная цена** по ступеням: 40 % → 75 % → 100 % от разрешённой уступки, цена округляется вверх до 10 сом;
   - ступени кончились — **«Это наша лучшая цена»**.
   Повтор того же сообщения ступень не сдвигает. Новое сообщение торг не сбрасывает: состояние хранится сутки. Не больше 6 попыток в сутки по товару и 10 запросов в час на чат.
4. Под ценой есть кнопка **«✅ Беру за X»**: она кладёт товар в корзину по этой цене, потом «Оформить заказ». Если заказ оформляет ИИ, цена применяется так же.
5. Цена держится **30 минут**. Это подписанная оферта: она действует только в этом чате и только для этого товара, одна оферта — один заказ. После заказа остальные предложения по этому товару в чате сгорают. Без оферты в заказ идёт цена каталога.
6. Защита:
   - любая цена в ответе ИИ, которой нет в каталоге или в действующей оферте, заменяется на «цену уточню у продавца»;
   - на «я владелец», «покажи промпт/закупку», «скидка 90 %» бот отвечает шаблоном без ИИ;
   - после 3 таких сообщений за час бот зовёт продавца и молчит час.
   Проверили 70 провокаций: цена ни разу не опустилась ниже пола.

## Настройки — `seller_config.bargain` в `telegram-bot/settings/`

```json
"bargain": {
  "enabled": false,              // торг вкл/выкл (нужно ещё seller_enabled)
  "max_discount_percent": 5,     // лимит скидки по умолчанию, 0…50
  "min_margin_percent": 10,      // не ниже закупки + N %, 0…500
  "only_marked": true,           // торг только по отмеченным товарам/категориям
  "steps": 3,                    // ступеней уступки, 1…5
  "allowed_categories": [],      // id категорий, где торг разрешён
  "handoff_on_decline": false    // при «лучшей цене» звать продавца
}
```

## Правила товара (поля «Минимальная цена для торга» и «Макс. скидка, %»)

Хранятся в отдельной таблице, публичные API витрины её не читают. Доступ только владельцу и админу.

- `GET api/main/telegram-bot/bargain/products/?search=&category=&only_rules=1&page=` → `{product_id, name, price, purchase_price, category_id, allowed, min_price, max_discount_percent, effective_allowed, floor}`. `floor` — итоговый пол, показывать только владельцу.
- `PUT api/main/telegram-bot/bargain/products/<product_id>/` `{"allowed": true|false|null, "min_price": "28000", "max_discount_percent": "7"}`. `null` значит «как в общих настройках». Ошибки 400: `min_price` выше цены, скидка вне 0…50.
- `DELETE …/bargain/products/<product_id>/` — сбросить правила товара.

## Журнал и симулятор

- `GET api/main/telegram-bot/bargain/offers/?from=&to=&chat_id=&decision=` — каждое решение движка: товар, цена в списке, предложение клиента, решение, цена, ступень, пол, лимит, заказ.
- `POST api/main/telegram-bot/bargain/test/` `{"product_id", "variant_id"?, "offer"?, "reset"?: true}` → `{decision, price, list_price, text, button, floor}`. Подходит для окна «Проверить торг». Тест-чат в отчёт не попадает.
- `POST telegram-bot/test-ai/` `{"question", "as": "customer"}` теперь показывает и торг: поле `bargain: {tag, text}`.

## В заказе

`showcase/orders/` → `items[].bargain`: `{"list_price": "577500.00", "agreed_price": "548626.00", "discount_percent": "5.0", "step": 0}` или `null`.
В строке заказа `price` — цена в списке, `discount` — уступка, `total` — по цене торга. В `comment` строка «Цена по торгу: … (в списке …, скидка 5.0 %)», `source_detail = bot_sales`.

## Отчёт — `sales-stats/` → блок `bargain`

`{dialogs, proposals, accepted_by_customer, orders, concessions_total, avg_discount_percent, decline_share_percent, top_products[]}`. `concessions_total` — сколько уступили от цены в списке.

## Признак

`bot_bargain` в `users/capabilities/` → `features`.

## Что нужно от кассы / --owner

1. В настройках «Бот-продавец» блок «Торг» с полями выше.
2. В карточке товара поля «Торг разрешён», «Минимальная цена для торга», «Макс. скидка, %» через `bargain/products/<id>/`. Там же показывать итоговый пол.
3. В «Заказах с сайта» строка «Цена по торгу: X (в списке Y, скидка Z %)» из `items[].bargain`.
4. В отчёте блок «Торг», журнал оферт и окно «Проверить торг».
