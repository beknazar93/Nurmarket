**Просьба владельца (06.11.2026):** «Маркетплейс должен открываться с нашего сайта, и оттуда при покупке в программу скачиваются дополнительные функции и темы программы».

**Что уже сделано в кассе (сборка 1.17.80, ждёт вашего сервера):**
1. Кнопка «Открыть Маркетплейс на сайте» в окне «Маркетплейс» (касса, программа владельца, Android). Адрес — настройка `MarketplaceWebUrl`, по умолчанию **`https://market.nurcrm.kg/crm/marketplace`** — **проверьте и подтвердите** реальный адрес раздела «Маркетплейс» (в вашем ТЗ от 31.10 он назван «front-market, раздел Маркетплейс, Бета-тест»; точного пути в документах нет). К адресу касса добавляет `?item=<код>` (`kassa-loyalty`, `theme-sunset`): откройте при таком параметре карточку этой функции/темы. **Токен в адрес не передаётся** — вход на сайте клиент делает сам.
2. «Купил на сайте — программа подхватывает»: когда окно «Маркетплейс» снова активно (вернулись из браузера) и по кнопке «Обновить покупки» касса сразу (не чаще раза в 20 с) запрашивает `GET users/company/addons/` и каталог тем; пишет «Подключено новых функций: N (названия)» или «Новых покупок не найдено». Фоновая проверка раз в 15 минут остаётся; после заявки «Подключить» 15 минут идёт проверка раз в минуту. **От вас для функций ничего нового не нужно** — работает ваш `company/addons/` из ТЗ 31.10.
3. Темы и виды кассы с сервера — **ждёт вас** (ниже). Без признака `marketplace_themes` касса ведёт себя как раньше (только свои темы), ошибок нет.

## 1. Что нужно от сервера

### 1.1. Признак
В `GET api/main/capabilities/` — **`marketplace_themes`** (когда готовы пункты 1.2–1.4). Касса показывает вкладку серверных тем только при этом признаке.

### 1.2. Каталог — `GET /api/main/marketplace/themes/` (с токеном)
Ответ — массив или `{results:[…]}`. Для компании токена — её `entitled`.

```json
[
  {
    "id": "12",
    "code": "theme-sunset",
    "kind": "theme",
    "name": {"ru": "Закат", "ky": "Күн батыш", "en": "Sunset", "tr": "Gün batımı", "uz": "Shom"},
    "description": {"ru": "Тёплая тема для магазина одежды. Подходит для…", "ky": "…", "en": "…", "tr": "…", "uz": "…"},
    "preview_url": "https://market.nurcrm.kg/media/marketplace/themes/sunset.png",
    "version": "1.2.0",
    "price": 500,
    "currency": "сом",
    "entitled": true,
    "until": null,
    "package_url": "/api/main/marketplace/themes/12/package/",
    "sha256": "9f2c…(64 символа, hex)",
    "size": 2841,
    "min_app_version": "1.17.80",
    "web_url": "https://market.nurcrm.kg/crm/marketplace/themes/sunset",
    "accent": "#FF8800"
  }
]
```
- `id` и `code` — только латиница, цифры, `-`, `_`, до 64 знаков (из них касса строит адреса и имена; остальное записи отбрасывает). `code` = **`theme-<slug>`** (как `kassa-<id>` у функций).
- `kind`: **`theme`** (цвета, шрифт, скругление — касса ставит уже сейчас), `view` (вид кассы: раскладка), `labels` (шаблоны этикеток), `scale-profile` (профиль весов). Виды, кроме `theme`, касса пока показывает как «Скоро» — формат пакетов по ним согласуем отдельно (п. 3).
- `name`, `description` — на 5 языках (`ru, ky, en, tr, uz`); можно строкой (тогда считается русским). Нет перевода — касса берёт русский.
- `price`: число; `null` или `0` — бесплатно. `entitled: true` — **у компании есть право скачать** (куплено, действует, или бесплатно). Бесплатные — всегда `entitled: true`.
- `sha256` — **обязателен**, SHA-256 **тела ответа `package/` как есть** (байты), hex. Без него касса пакет не ставит. `size` — размер тела в байтах (касса сверяет).
- `min_app_version` — минимальная версия программы (`1.17.80`). Касса не скачивает пакет, если версия ниже, и пишет «Нужна версия X или новее».
- `web_url` — страница темы на сайте (https, домен `*.nurcrm.kg` или `front-market.vercel.app`); нет — касса откроет общий Маркетплейс с `?item=theme-<slug>`.
- `accent` — основной цвет для значка карточки (необязательно); `preview_url` — картинка превью (https, до 1 МБ, касса качает **без токена**, поэтому ссылка должна быть публичной; нет картинки — цветная плитка).
- Не больше 200 записей на компанию (лишние касса не читает).
- Лишние поля касса игнорирует — можно добавлять свои.

### 1.3. Пакет — `GET /api/main/marketplace/themes/{id}/package/` (с токеном)
- **Только при `entitled`.** Иначе **403** `{"code":"not_purchased"}` (касса пишет «Тема не куплена — Купить на сайте»). 404 — нет такой темы; 410 — снята с продажи.
- Тело — **JSON данных, без исполняемого кода** (ни скриптов, ни ссылок «скачай ещё»). Размер **до 5 МБ** (касса отвергает больше, читая не дальше предела).
- Формат `theme` — тот же, что даёт «Редактор тем» кассы при «Экспорт» (файл `*.nmtheme.json`):
```json
{
  "format": "nurmarket-theme",
  "version": 1,
  "theme": {
    "name": "Закат",
    "baseThemeId": "classic",
    "light": {"accent":"#FF8800","accentText":"#FFFFFF","background":"#FFF8F0","panel":"#FFFFFF","text":"#2B1B0E","textSoft":"#7A6652","success":"#2E9E5B","warning":"#E0A100","danger":"#D64545"},
    "dark":  {"accent":"#FFA64D","accentText":"#1A1008","background":"#17110B","panel":"#211810","text":"#F5EBDD","textSoft":"#B9A58C","success":"#4CC080","warning":"#F2B829","danger":"#FF6B6B"},
    "cornerRadius": 10,
    "fontSize": 14
  }
}
```
  Касса берёт **только эти поля**: девять цветов (`#RGB`/`#RRGGBB`, остальное отбрасывается), `cornerRadius` 0–24, `fontSize` 12–18, `baseThemeId` (встроенная тема-основа, иначе «classic»), `name` до 60 знаков. Всё прочее игнорируется. Вложенность JSON не глубже 16.
  Сервер должен сам проверять контраст текста/фона (WCAG AA), как у тем сайта.
- Ответ `Content-Type: application/json`; `Content-Length` желателен (по нему касса сразу отклоняет слишком большое).
- Касса отправляет токен **только** на ваш сервер NurCRM: `package_url` с другим хостом касса не использует (берёт стандартный адрес выше). Если пакет лежит на CDN — отдавайте с `package/` редирект 302 на подписанную ссылку (касса следует редиректу штатным клиентом) либо проксируйте.

### 1.4. Версии и откат
- `version` растёт при каждом изменении пакета (семвер). Касса показывает «Есть обновление», если изменились `version` или `sha256`; обновление — кнопкой «Обновить» (тема ставится на то же место, выбранная тема остаётся выбранной).
- Откат: `GET …/themes/{id}/package/?version=1.1.0` — пакет прежней версии (для поддержки; в кассе кнопки отката нет). Нужны ли история версий и откат на стороне сайта — на ваше усмотрение.
- Если тему сняли с продажи, а у компании она куплена, — `entitled` остаётся `true`, пока действует право (ранее установленная тема в кассе остаётся и после).

### 1.5. Связь покупки на сайте и кассы
1. Клиент в веб-админке (Маркетплейс → тема) нажимает «Купить»; оплата (сейчас через поддержку/заявку, позже онлайн — для кассы всё равно).
2. Сервер ставит компании право на тему: в каталоге `entitled: true` и в `GET users/company/addons/` появляется `{ "code": "theme-sunset", "active": true, "until": null|"2027-01-01" }` (**ваш общий каталог платных вещей** — тот же `company/addons/`, что у функций кассы; код темы `theme-<slug>`, как `kassa-<id>` у функций).
3. Касса при возвращении из браузера (или «Обновить покупки», или при открытии Маркетплейса) запрашивает каталог; видит `entitled: true`; если включено «Устанавливать купленные темы автоматически» (по умолчанию да) — скачивает пакет и ставит тему. Если выключено — карточка показывает «Установить».
4. Выключили на сервере (`entitled: false`) — установленная тема остаётся в кассе (это данные), но обновления и повторная установка недоступны (403).
5. Срок (`until`) — только для показа в кассе; право проверяет сервер при скачивании.
6. Все ответы касса кэширует (по компании); без интернета каталог берётся из кэша, скачанные темы работают.

### 1.6. Безопасность (обязательно)
- Пакет — **только данные**. Касса ничего не исполняет и не загружает по ссылкам из пакета. Не добавляйте в пакеты код, ссылки на скрипты, HTML.
- Подпись/хэш: `sha256` в каталоге (обязателен). Если захотите подпись ключом (ed25519) — скажите, добавим проверку (поле `signature`); пока хватает хэша по HTTPS.
- 403 `not_purchased` — для чужих и неоплаченных. Не отдавайте пакет без `entitled` (даже по угаданному `id`).
- Ограничение частоты: касса спрашивает каталог не чаще раза в 20 с (вручную) и раз в 5 минут (при открытии окна).

## 2. Дополнительные ФУНКЦИИ (платные карточки кассы)

Новые платные функции — это **код в программе**, его нельзя «скачать». «Скачивание при покупке» для функций = **включение** (ваш `company/addons/`, `kassa-<id>`) + **догрузка данных функции**. Что работает сейчас (проверено, тесты есть):
- `kassa-language` (языковой пакет): словари en/tr/uz встроены в программу, при покупке на сайте они **открываются сразу без перезапуска** (переключатели языка в Настройках появляются сами).
- `kassa-labeleditor`, `kassa-pricetag`, `kassa-bulktag`, `kassa-scales`, `kassa-loyalty` и др.: пункты меню/кнопки включаются сразу после проверки покупок (меню владельца пересобирается, в кассе проверка идёт при нажатии).

**Что можно добавить с вашего сервера (предложение, если решите):**
1. Пакеты данных функций — тем же способом, что темы (`kind`: `labels` — шаблоны этикеток, `scale-profile` — профили весов, `view` — раскладки): `GET …/themes/{id}/package/` с `entitled`, хэшем и размером. Касса ставит их в ту же папку данных компании. Форматы пакетов `labels` и `scale-profile` — по существующим файлам кассы (`label-template.json`, `label-scales.json`); пришлём образцы по вашему запросу.
2. Переводы языкового пакета отдельным пакетом (`kind: "lang"`): новые языки/строки без выпуска новой версии. Сейчас переводы вшиты в программу.
3. Шаблоны ценников/этикеток «от дизайнеров» как платные пакеты (отдельная карточка в Маркетплейсе).

## 3. Вопросы
1. Точный путь раздела «Маркетплейс» в веб-админке и поддерживает ли он `?item=<код>` (открыть карточку)? Иначе касса будет открывать общий раздел.
2. Подтвердите коды: `theme-<slug>` для тем; для видов/этикеток/весов предлагаем `view-<slug>`, `labels-<slug>`, `scale-<slug>` (тот же `company/addons/`).
3. Нужен ли одинаковый каталог для кассы и программы владельца (по умолчанию да: одна компания — один каталог, установленные темы у каждой программы свои).
4. Для `preview_url` — публичная ссылка без токена: подтвердите (иначе превью не показывается, остаётся цветная плитка).

**Проверка (когда сервер готов):** тестовая компания NBS: в каталоге 2–3 темы (одна бесплатная, одна платная куплена, одна не куплена); `capabilities` содержит `marketplace_themes`; касса: «Маркетплейс» → «Темы» → купленная ставится одним нажатием, не купленная — «Купить на сайте» открывает сайт; после покупки на сайте и возврата в кассу — «Подключено новых функций / Куплено новых тем» и тема сама появилась в списке.
