# Видеоуроки NurCRM — формат и список (29.10.2026)

Для кого: владелец и кассир магазина в КР, смотрят с телефона, часто без звука. Касса 1.17.64+, программа владельца (тот же exe, `--owner`), мобилка 1.18.8+. Языки: голос **ru** и **uz** (две дорожки, один видеоряд с перезаписанными экранами на нужном языке), **ky — субтитры** поверх ru-дорожки (решение владельца 23.10, см. память `video-lessons-todo`). en/tr не делаем.
Все шаги — только то, что есть в программе (проверять по `docs/AI_HANDOFF.md` 2.2 и приёмкам в `docs/Отчеты/`). Стенд — тестовый аккаунт NBS; настройки настоящей кассы владельца не трогать.

Правила: 1–3 минуты, лучше 90 с; один урок — одна задача; темп речи спокойный, 2,3 слова/с; говорить «нажмите», «выберите», не «кликните»; цифры в стенде правдоподобные (сом, товары NBS); никаких реальных имён клиентов, кодов удалённой помощи и ключей. Голос ru — тот же, что в рекламе; uz — носитель. Перед записью каждого урока — подготовить данные стенда (колонка «Данные» ниже), очистить корзину, закрыть баннер обновления.

Имя файла: `K-03-vozvrat-ru.mp4`, `V-02-otchety-uz.mp4`, `M-05-ii-ru-ky.mp4` (K — касса, V — владелец, M — мобилка). Плейлисты на YouTube по трём программам, порядок — как номера.

## 4. Что подготовить один раз

- Стенд NBS: открытая смена, 10 товаров с фото и остатками (среди них «пачка 20», весовой, товар без штрихкода), 3 клиента (бонусы, долг, ДР), 2 сотрудника с процентами зарплаты, 1 филиал, накладная xlsx/XML/CSV на 8–10 строк, ключ Gemini, тестовый ключ модуля ценников.
- Сценарий каждого урока — 1 страница: реплики ru по шагам (≤ 25 слов на шаг), что в кадре, где зум; перевод uz и ky — из этого же файла.
- Проверка перед публикацией: нет кодов/ключей/реальных имён в кадре; версия программы в титре финала («для NurCRM 1.17.64»); при выходе новой версии с изменённым экраном — переснять только тело урока, заставка/финал общие.
