## 1. Что программа реально умеет (проверено по коду, ничего не выдумано)

Касса NurMarketKassa.Avalonia (программа владельца — тот же exe с `--owner`; реальные файлы: `Views.axaml/Main/DebtReminderWindow.cs`, `Services/DebtReminderPlanner.cs`, `Views.axaml/Main/DebtsWindow.cs`, `AiAdvisorWindow*.cs`, `OwnerShellWindow.Attention.cs`).

**Где увидеть долги.**
1. «Сводка» → блок «Требует внимания» → строка «Долги клиентов: N сом · Должников: K · Больше 30 дней: M сом» → «Долги ›» (раздел «Долги клиентов»).
2. Раздел «Долги клиентов» (`DebtsView`): итог «Вам должны …», давность (до 7 дней / 8–30 / больше 30), карточка каждого должника — сумма, с какого числа, телефон, его чеки в долг. На карточке кнопка «Напомнить в WhatsApp» (текст с именем и суммой; у клиента без телефона или с чужим номером кнопка выключена, рядом объяснение).

**Окно «Напоминания должникам»** (`DebtReminderWindow`; открывается из Нур Советника: ⚙ → «Напоминания должникам…», кнопка «✉ Напомнить должникам» или карточка «Пора напомнить»).
1. Вкладка «Кому напомнить»: список должников с просрочкой (по умолчанию от 7 дней), у каждого — телефон, дни просрочки, «ещё не напоминали» или «напоминали 21.10 (WhatsApp)», сумма красным. Отмечены сразу все, кому пора; пропущенные показаны с причиной («недавно напоминали», «исключён», «нет телефона и не подписан на бота»). «Ещё не просрочены» в список не попадают. «Отметить всех / Снять все», «Обновить».
2. Справа — предпросмотр текста выбранного клиента: «Здравствуйте, Токтогул-ата! Это магазин «Нур». Напоминаем о долге 118 000 сом (уже 41 дн.). Пожалуйста, верните долг, когда сможете. Спасибо!». Язык сообщения — на каждого клиента свой: русский, кыргызский, узбекский. «Исключить из напоминаний» / «Вернуть».
3. Кнопка «Открыть WhatsApp по очереди (N)»: перед первой отправкой — подтверждение списка («Подтвердите список: напомнить о долге 4 клиентам — …»). В Windows открывается встроенный WhatsApp Web (вход по QR сохраняется) с уже вписанным текстом; «Отправить» нажимает владелец сам — программа ничего не отправляет. Следующий должник открывается в том же окне кнопкой «Следующий ▶ Имя (2 из N)». В журнал пишется «WhatsApp — открыт чат» (телефон в журнале программы — только первые 4 цифры). На Linux/Android/Mac — ссылка wa.me.
4. Кнопка «Отправить в Telegram (N подписанных)»: только тем, кто нажал «Старт» у бота магазина; перед отправкой подтверждение; одному клиенту не чаще раза в 3–7 дней (по умолчанию 7). Выключена, если бот не настроен (Настройки → Telegram) или недоступен на тарифе.
5. «Напомнить завтра» — карточка «Пора напомнить» в Советнике не появится до завтра 10:00.
6. Вкладка «Журнал» — кому, когда, каким каналом и с каким результатом.
7. «Расписание и текст» (раскрывающаяся панель): «Напоминать по расписанию» (вкл/выкл), «Раз в (дней)» — 7, «Просрочка от (дней)» — 7, «Одному клиенту не чаще раза в (3–7 дней)», «Тихие часы с 21 до 9» (в это время кнопки отправки выключены: «Тихие часы 21:00–09:00: клиентам не пишем»), язык по умолчанию, три шаблона текста (ru/ky/uz) с подстановками `{name}`, `{amount}`, `{shop}`, `{days}`, «Вернуть стандартный текст». Хранится в `debt-reminders.json` в папке данных (настройки, исключённые, журнал).

**По расписанию.** В Нур Советнике на пустом экране появляется карточка «✉ Пора напомнить 4 должникам с просрочкой > 7 дн.» и кнопка «Проверить список» (открывает окно выше). Она показывается, если: напоминания включены, не тихие часы, не нажато «Напомнить завтра», с прошлого раза прошло «раз в N дней», есть должники с просрочкой. Сама по себе ничего не отправляет.

**Нур Советник (вопрос текстом/голосом).** «Кто должен больше всех?» → таблица должников; если просят напомнить, ИИ отвечает строкой `НАПОМНИТЬ: [Д1], [Д2]` → программа рисует карточку должников с кнопкой «Написать в WhatsApp» (чат с готовым текстом, отправляет владелец) и «Следующий ▶». Данные клиентов в ИИ не уходят (только коды [Д1]); без права «Клиенты» — отказ.

**Telegram-бот магазина.** Клиент нажимает «Старт» по ссылке с чека/кассы → привязан к своему долгу, кнопка «💳 Мой долг» и напоминания приходят ему в Telegram. Владельцу: команда `/dolgi` — список должников со ссылками WhatsApp для неподписанных; Настройки → Telegram → «Напоминания должникам» — рассылка всем подписанным сразу (одному чату не чаще раза в 20 часов, заблокировавшие бота отписываются).

**Мобилка NurMarketMobile.** Отдельной «рассылки/напоминаний» нет. Есть «Долги клиентов» (`ops_screens.dart`: список должников и «Принять оплату долга», без звонка/WhatsApp) и «Клиенты» (`admin_screens.dart`: карточка с долгом красным и кнопка «WhatsApp» — открывает чат с номером, но с ПУСТЫМ текстом, шаблона напоминания нет; звонка/SMS нет). Отдельная фича «звонок/WhatsApp из карточки должника» не найдена → **второй ролик (17) не нужен**, чтобы не выдумывать; мобилку в ролике 16 не показываем.

## 3. Откуда экраны (честность)

Снимки — настоящие окна программы владельца на стенде `C:\Users\User\NurMarket-video\stands\ad-features` (сцены `FeatDebts.cs`, запуск `bash run1.sh ru light 16-owner-attention …`): headless-Avalonia, сервер подменён заглушкой в памяти, база в песочнице, запись настроек выключена; профиль владельца не использовался. Магазин «Нур», должники — выдуманные Токтогул-ата / Бүбү-апа / Эрлан / Жылдыз / Бакыт, суммы 118 000 + 82 000 + 45 000 + 20 000 + 10 000 = 275 000 сом, телефоны `+996 555 00 00 0N`. Бакыт (долг 3 дня) — «ещё не просрочен», в список напоминаний не попадает (так и показано: «ещё не просрочены: 1»). Состояния «Следующий ▶ …» и карточка в Советнике — настоящие элементы окна: состояние очереди выставлено теми же полями, что ставит нажатие «Открыть WhatsApp по очереди»; в Советнике права владельца включены только в памяти стенда.

Чего НЕТ и почему: окно WhatsApp Web (встроенный браузер, нужен вход по QR) в стенде не поднимается — вместо него схема №4 (подписана как схема, показывает только текст сообщения из шаблона программы, без номеров и без оформления WhatsApp). Telegram-ветка в кадр не вошла: на стенде бот не подключён («0 подписанных») — упомянута только здесь.

Расхождения «задания» и программы: напоминание — не «рассылка в один клик»: WhatsApp открывается по очереди, «Отправить» жмёт владелец; Telegram — только подписанным и после подтверждения. Ролик говорит именно так. «Напоминание по датам» — это не дата долга, а расписание «раз в N дней + просрочка от N дней + тихие часы».
