# ИИ-агенты для звонков и ответов клиентам: открытые проекты на GitHub (22.10.2026)

_Просьба владельца: «найди ИИ-агентов в GitHub для звонков и ответов клиентам». Это продолжение исследований 18.10 («Голосовые ИИ-операторы…») и 20.10 («ИИ-боты и звонящий ассистент»). Готовые платные платформы (ElevenLabs, Vapi, Retell) там уже сравнены, здесь — **открытый код**, который можно запустить у себя, и что из него подходит NurMarket. Ничего не устанавливали и не клонировали: только чтение страниц GitHub, Hugging Face и документации._

**Пометки:** **[не проверено]** — первоисточник не найден или он сторонний; **[оценка]** — наш расчёт. Звёзды, даты коммитов и выпусков сняты со страниц GitHub **22.10.2026**. Цены в долларах без НДС, ≈ 87 сом за $1 **[оценка]**. Это не юридическая консультация.

## 0. Коротко

**Голосовые звонки — топ-3 открытых проекта:**
1. **LiveKit Agents + LiveKit SIP** (Apache-2.0, 14,9 тыс. ★, выпуск 15.10.2026) — лучше всех с телефонией: свой SIP-сервер, любой SIP-оператор, входящие и исходящие, перевод на продавца (SIP REFER), тоновый набор, шумоподавление. Готовый модуль Gemini Live. **Выбор для пилота.**
2. **Dograh** (BSD-2, 5,9 тыс. ★, выпуск 12.10.2026) — готовая «открытая замена Vapi/Retell» с конструктором сценариев и панелью, запускается одним Docker. Внутри — Pipecat. Подходит, если нужна панель без программирования.
3. **AVA — AI Voice Agent for Asterisk** (MIT, 1,3 тыс. ★, выпуск 17.10.2026) — если звонки пойдут через свою Asterisk/FreePBX от местного оператора: Google Live, OpenAI Realtime, Deepgram, ElevenLabs; HTTP- и MCP-инструменты, перевод, автоответчик.

Запасной движок вместо LiveKit — **Pipecat** (BSD-2, 16,7 тыс. ★, выпуск 19.10.2026): больше всего готовых модулей, но телефония через WebSocket не умеет перевод звонка.

**WhatsApp / Telegram / Instagram — топ-3:**
1. **Свой бот на сервере** на уже знакомой библиотеке **Telegram.Bot** (.NET, MIT) + официальный **WhatsApp Cloud API** + Gemini с теми же инструментами, что у голосового агента. Это часть 29.1 ТЗ; готовый «ИИ-агент» с GitHub не даст главного — наших данных и правил.
2. **Chatwoot** (MIT в бесплатной версии, 38 тыс. ★, выпуск 20.10.2026) — общий ящик сообщений для продавцов: Telegram, WhatsApp, Instagram, сайт; наш бот подключается как «Agent Bot» и передаёт разговор человеку. Встроенный ИИ Captain — **только платный**.
3. **Evolution API** (Apache-2.0 с условиями, 9,9 тыс. ★) — шлюз WhatsApp (неофициальный через Baileys или официальный Cloud API), уже связан с Chatwoot, Typebot, n8n, Dify. Неофициальный режим — **риск блокировки номера**.

**Главный риск — кыргызский язык.** Проверили отдельно (раздел 3):
- **Whisper (OpenAI) кыргызского не знает вовсе** — его нет в списке языков модели. Так же нет кыргызского у **Deepgram**, **Soniox**, **Ultravox**, Azure, Yandex. А почти все открытые агенты по умолчанию берут Deepgram или Whisper.
- Кыргызский «из коробки» в реальном времени есть только у **Gemini 3.8 Live** (распознавание + голос, в официальном списке) и у **ElevenLabs** (голос v4/v4 Turbo; потоковое распознавание не подтверждено).
- Открытые кыргызские модели есть (Kyrgyz Whisper от NineNineSix, BuzzASR, Meta Omnilingual, KaniTTS), но ошибка распознавания у них **20–45 % слов** на чистых тестах, а не на телефоне.
- Поэтому пилот — **LiveKit + Gemini 3.8 Live**, кыргызский — «проверяем», а не «обещаем».

**Телефония в КР:** у **Twilio номеров КР не нашли**, исходящий звонок на мобильный КР у Twilio — $0,39 за минуту. Реальные пути: номер Бишкека у **Zadarma** ($4–8 в месяц) или SIP-транк от **ВАТС Beeline**/Sipuni, с переадресацией «не ответил» с номера магазина на агента.

**Цена пилота** (1 магазин, только пропущенные звонки, ~1800 минут в месяц): **≈ $90–130 в месяц (≈ 8–11 тыс. сом)** **[оценка]**. Срок: ~10 рабочих дней на сборку и проверку + 1 месяц пилота.

### 2.2. Важные правила каналов

- **WhatsApp:**
  - **официально — только Cloud API (Meta)**: шаблоны платные, служебные ответы в течение 24 часов после сообщения клиента — бесплатно (исследование 20.10);
  - **с 15.01.2026 Meta запрещает в Business API «общие ИИ-ассистенты»** (как ChatGPT), а боты магазина для поддержки, заказов, статусов и уведомлений **разрешены** ([respond.io](https://respond.io/blog/whatsapp-general-purpose-chatbots-ban)). Значит, наш бот должен отвечать только о магазине;
  - **Baileys, whatsapp-web.js, wppconnect, режим Baileys в Evolution API** — это неофициальный «WhatsApp Web»; нарушает правила WhatsApp, **номер могут заблокировать**, особенно при рассылках и жалобах ([обзор 2026](https://zylos.ai/research/2026-01-26-whatsapp-api-automation)). Для пилота у одного магазина — можно, для всех магазинов — нет.
- **Telegram:** официальный Bot API, наш бот уже есть, нужно перенести его на сервер (часть 29.1).
- **Instagram:** только через Meta (Instagram Messaging API, бизнес-аккаунт + страница Facebook, окно 24 часа). Проще всего — через Chatwoot, у которого канал Instagram готов ([README Chatwoot](https://github.com/chatwoot/chatwoot)).

### 2.3. Как это собрать

```
Покупатель ─► Telegram / WhatsApp Cloud API / Instagram
                         │
                         ▼
             Chatwoot (общий ящик, у нас на сервере)
                         │  событие message_created → webhook
                         ▼
     Наш бот-агент (на сервере): Gemini + 10 инструментов (как у звонка)
                         │  ключ API точки (ТЗ 29.4)
                         ▼
            NurCRM: товары, остатки, долг звонящего, заказ-черновик
```

- **Chatwoot Agent Bot:** при подключённом боте новый разговор получает статус «ожидает», бот отвечает через API; чтобы позвать продавца — бот ставит статус «открыт», и разговор видит человек ([Agent Bots](https://chatwoot.com/docs/product/others/agent-bots)). Платный Captain не нужен.
- **Без Chatwoot** (минимум): Telegram.Bot + webhook на сервере, WhatsApp Cloud API напрямую — меньше частей, но продавцам негде отвечать вручную.

## 5. Как подключить к NurCRM

- **Агент не ходит в кассу** (она бывает выключена) — только в API NurCRM `app.nurcrm.kg`.
- **Ключ точки** с правами `catalog:read`, `stock:read`, `client:read_self`, `order:draft` — ТЗ **29.4**. Пока его нет, пилот — на тестовой компании NBS, с отдельным служебным входом «только чтение» (ключ хранится только на сервере агента, не в коде).
- **Инструменты агента** (одни и те же для звонка и бота, не больше ~10 — раздел 3.5 исследования 20.10): `get_store_info`, `search_products` (29.5), `check_stock`, `find_caller` по номеру +996 (29.6), `get_client_debt` только для звонящего, `create_order_draft` с `Idempotency-Key` (29.7), `get_order_status`, `transfer_to_human`, `create_callback_task`, `end_call`.
- **Журнал звонков** — `POST /voice/calls` (29.8), сводка звонка владельцу в Telegram.
- **Никаких денег:** у агента нет оплаты, скидок, изменения цены и закрытия долга.
- Пока поиска товара на сервере с опечатками и транслитом нет (29.5), агент может искать по выгрузке каталога точки в памяти своего сервера (обновлять раз в 5–10 минут) **[оценка]**.

## 6. Рекомендация и план пилота

### 6.1. Почему LiveKit + Gemini 3.8 Live

- **Кыргызский:** Gemini Live — единственный режим «речь→речь» с `ky` в официальном списке, у нас уже есть ключ и опыт (Нур Советник, `GeminiLiveVoice.cs`). Модель 3.8 Live поддерживает асинхронный вызов функций — агент может сказать «секунду, смотрю» и не молчать, пока идёт запрос в NurCRM ([возможности](https://ai.google.dev/gemini-api/docs/live-api/capabilities)).
- **Телефония:** LiveKit — единственный из открытых, у кого свой SIP-сервер со всем нужным: любой оператор, перевод на продавца, тоновый набор, шумоподавление.
- **Живой и с открытой лицензией:** Apache-2.0, выпуски каждую неделю, можно вынести всё на свой сервер.
- **Не привязаны:** если кыргызский у Gemini окажется плохим, в том же агенте меняем модель на ElevenLabs (распознавание Scribe + голос v4 Turbo) без смены телефонии.
- **Ограничение Gemini Live:** сессия только со звуком — до 15 минут ([там же](https://ai.google.dev/gemini-api/docs/live-api/capabilities)); нам хватает (лимит звонка 4–5 минут).

**Когда выбирать другое:**
- нужна панель «как Vapi», где владелец сам рисует сценарий, — **Dograh**;
- оператор даёт ВАТС/Asterisk и не даёт внешний SIP — **AVA для Asterisk** (модуль Google Live есть);
- нужен самый быстрый запуск без своего сервера — **ElevenLabs Agents** (закрытый, исследование 20.10).

### 6.2. Что развернуть и на чём

| Часть | Пилот | Позже |
|---|---|---|
| Номер | Zadarma, Бишкек, $4–8/мес | SIP-транк ВАТС Beeline / местного оператора |
| SIP и медиа | **LiveKit Cloud** (меньше настройки, $0,01/мин агент + $0,01/мин телефония) | Свои livekit-server + livekit-sip (нужен белый IP, открытые порты UDP для RTP) |
| Агент | Python-воркер LiveKit Agents + модуль Google (Gemini 3.8 Live) в Docker | То же |
| Сервер агента | **Отдельный небольшой VPS** (2 ядра, 4 ГБ, ~$10–20/мес) **[оценка]**. VPS `support.nurcrm.kg` технически подойдёт, но лучше не смешивать с удалённой помощью: сбой звонков не должен ронять помощь кассам | Рядом с бэкендом NurCRM |
| Данные | NBS через служебный вход «только чтение» | Ключ точки (29.4) |
| Отчёт | Сводка звонка в Telegram владельцу | Журнал 29.8 в NurCRM и в программе владельца |

### 6.3. Шаги и сроки (~10 рабочих дней + месяц пилота)

| Дни | Что | Результат |
|---|---|---|
| 1–2 | Номер Zadarma, SIP-транк в LiveKit, пример агента на Gemini 3.8 Live | Звоним на номер — агент отвечает |
| 3–5 | Инструменты к NurCRM (NBS): информация о магазине, поиск товара и остатка, звонящий и его долг, черновик заказа, перевод на продавца, «перезвонить» | Агент отвечает о товаре и цене по нашим данным |
| 6–7 | Приветствие на двух языках (предупреждение о роботе и записи), правила промпта, лимит 5 минут, выход при тишине, сводка в Telegram | Готов к живым звонкам |
| 8–10 | Проверка: 50–100 фраз покупателей (шум, мобильная связь, смесь языков), 5 носителей кыргызского оценивают; задержка, доля понятых названий и чисел | Решение «запускать / менять модель» |
| +1 месяц | Пилот на 1 магазине, только пропущенные звонки | Отчёт: сколько звонков, что понял, что нет, стоимость |

Текстовые каналы — параллельно, но **сначала бот на сервере** (29.1), затем Chatwoot + WhatsApp Cloud API для одного магазина.

### 6.4. Стоимость пилота в месяц [оценка]

Один магазин, ~30 пропущенных звонков в день × 2 мин ≈ **1800 минут**.

| LiveKit Cloud | 1800 × ($0,01 + $0,01) | 36 |
| Номер Zadarma | | 4–8 |
| VPS агента | | 10–20 |
| Переадресация у оператора магазина | **[не проверено]** | 0–15 |

Для сравнения (исследование 20.10, 6000 мин/мес): Gemini + LiveKit ≈ $210–300, ElevenLabs ≈ $520–580, Vapi ≈ $720–1100. Без LiveKit Cloud (всё на своём сервере) — минус ~$36, но больше работы. Исходящий обзвон должников по мобильным — **отдельно**: $0,16–0,28/мин у Zadarma, $0,39 у Twilio, поэтому напоминания — сначала через Telegram/WhatsApp.

## 7. Риски

| Риск | Насколько | Чем закрыть |
|---|---|---|
| **Кыргызский понимается плохо** (шум, 8 кГц, смесь с русским, диалекты); Whisper, Deepgram, Soniox его вообще не знают | **Высоко** | Gemini 3.8 Live или ElevenLabs, проверка 50–100 фраз до пилота; номер звонящего — из звонка, а не диктовкой; после двух непониманий — перевод на продавца; кыргызский — «пробуем», русский — по умолчанию |
| **Узбекский** (юг КР) | Средне | Gemini Live и ElevenLabs (голос) его знают; проверять так же |
| **Качество связи и задержка** (мобильная сеть, серверы Google в ЕС/США) | Средне | Цель ответа ≤ 1,2 с; «секунду, смотрю»; LiveKit Cloud ближайший регион; запасной путь — переадресация на живой номер |
| **ИИ ошибся с товаром или суммой** | Высоко | Цифры только из инструментов; без денежных инструментов; заказ — черновик, продавец подтверждает |
| **Закон о персональных данных** (Цифровой кодекс с 05.02.2026; закон № 150 — штрафы 65–140 тыс. сом) | Средне–высоко | В начале звонка: «вам отвечает виртуальный помощник, разговор записывается»; уведомление, что данные обрабатываются за рубежом (Google); записи 30–90 дней; долг — только своему номеру ([ICNL](https://www.icnl.org/post/news/kyrgyzstans-digital-code-understanding-and-complying-with-personal-data-provisions), [закон № 150](https://economist.kg/vlast/2026/10/13/personalnye-dannye-shtrafy-140-tys-2/)) |
| **Запись звонков и роботы-звонари** | Средне | Явной нормы КР о записи и автоматических звонках **не нашли**. В России с 2025 автоматические звонки без согласия запрещены ([Битрикс24 о 41-ФЗ](https://www.bitrix24.ru/journal/holodnye-zvonki/)) — ориентир, не закон КР. Исходящие — только тем, кто согласился, 10:00–19:00; спросить юриста |
| **Блокировка WhatsApp** при неофициальных библиотеках; запрет «общих ИИ-ассистентов» в Business API с 15.01.2026 | Средне | Для всех магазинов — только Cloud API; бот отвечает только о магазине |
| **Лицензии** (TEN, Dify, n8n, Typebot, Evolution API) | Средне | Брать MIT/Apache/BSD (LiveKit, Pipecat, Dograh, AVA, Chatwoot CE, Telegram.Bot); у Evolution API — показывать пометку |
| **Счёт за минуты** | Средне | Только пропущенные звонки, лимит 5 мин, месячный лимит минут, уведомление на 80 % |
| **Нет ключа точки и поиска на сервере** (ТЗ 29.4–29.7) | Средне | Пилот на NBS через служебный вход «только чтение»; для боевых магазинов — только после 29.4 |

## 8. Что не удалось проверить

- Качество кыргызского у Gemini 3.8 Live на телефонной линии (8 кГц) — никто не публиковал.
- Лицензия KaniTTS для кыргызского (`kani-tts-400m-ky`): в карточке противоречие «lfm1.0/other» и «Apache 2.0».
- Номера КР у Telnyx (тип, цена, документы); SIP-транк наружу у ВАТС Beeline, MegaCom, O!; цена переадресации с мобильного номера магазина.
- Есть ли готовый модуль Gemini Live именно в Dograh (внутри Pipecat он есть).
- Работает ли Chatwoot Agent Bot во всех каналах одинаково (официальная страница — 2023 года).
- Нормы КР о записи звонков и автоматических звонках.
- Цена Ultravox ($0,05/мин) — по сторонним источникам; лицензия примеров Google (`gemini-live-api-examples`).

# Бесплатно: звонки и голосовые в Telegram и WhatsApp (22.10.2026)

_Вопрос владельца: «найди БЕСПЛАТНЫХ ИИ-агентов для звонков через Telegram и WhatsApp Web и ответ на звонки». Без платной телефонии (без Zadarma, Twilio, SIP). Ничего не устанавливали и не клонировали. Звёзды и даты — со страниц GitHub 22.10.2026._

## 1. Коротко

1. **Самый реалистичный бесплатный вариант — голосовые сообщения, а не звонки.** Покупатель шлёт голосовое в Telegram или WhatsApp, Gemini понимает его (кыргызский, русский и узбекский есть в языках Live API), бот отвечает текстом и/или голосом. Telegram Bot API бесплатен, ответы в WhatsApp в течение 24 часов после сообщения клиента — тоже. Риска блокировки нет (официальные API).
2. **Звонки в Telegram:** боту (Bot API) принимать звонки нельзя. Остаётся «юзербот» — обычный аккаунт на отдельной SIM, которым управляет программа. Библиотека есть (PyTgCalls), но **готового ИИ-агента для личных звонков 1-на-1 на GitHub не нашли** — собирать самим. Риск блокировки аккаунта реальный.
3. **Звонки в WhatsApp:** есть **официальный Calling API** (Meta). **Входящие звонки бесплатны.** Открытые примеры есть (Pipecat, LiveKit). Но нужен бизнес-номер на Cloud API, суточный лимит не менее 2000 получателей и верификация, а исходящие платные и жёстко ограничены. Через «WhatsApp Web» (Baileys, whatsapp-web.js) звонок принять **нельзя** — только отклонить.
4. **«Бесплатно» на деле:** модель Gemini и сервер можно взять бесплатно для пробы, но бесплатный уровень Google использует данные для улучшения своих продуктов. Платными остаются исходящие звонки WhatsApp, Gemini при реальных клиентах и, возможно, номер.

Отвечать только тем, кто **сам позвонил или написал**, — риск заметно ниже. **Исходящие напоминания должникам юзерботом — самый рискованный сценарий.**

## 7. Топ-3 и план пробы без оплат

**Топ-3:**
1. **Голосовые сообщения в Telegram (вариант 1, начать с него).** Бесплатно, без риска, почти всё уже есть. Решает «клиент не хочет печатать».
2. **WhatsApp: те же голосовые и текст через Cloud API (вариант 1), затем входящие звонки через Pipecat (вариант 2).** Официально, входящие бесплатны. Путь длиннее: Meta, номер, лимит 2000.
3. **Telegram юзербот для пробы входящих звонков (вариант 4)** — только эксперимент на тестовом аккаунте и отдельной SIM, не для магазина: готового проекта нет, аккаунт могут ограничить.

Не рекомендуем: WhatsApp Web для звонков (не работает) и исходящие напоминания должникам юзерботом или неофициально (бан + закон).

## 8. Риски

- **Данные и закон.** Бесплатный уровень Gemini использует данные для улучшения продуктов Google. Реальные клиенты, долги и телефоны — только на платном уровне (раздел 1.7 исследования 20.10: Цифровой кодекс, закон № 150).
- **Кыргызский** в голосовых и звонках не проверен ни у кого. Голос в мессенджерах идёт в OPUS, это для распознавания обычно лучше телефонной линии **[оценка]**.
- **WhatsApp Calling API:** лимит 2000 получателей и верификация могут быть тяжелы для малого магазина; расхождение источников (1000 или 2000) проверять в кабинете Meta.
- **Блокировка:** юзербот Telegram и все неофициальные библиотеки WhatsApp.
- **Политика WhatsApp с 15.01.2026:** только боты по делу магазина (раздел 2.2 выше).
- **Условия Telegram, п. 1.5:** нельзя использовать данные Telegram для обучения ИИ. Мы не обучаем, но переписку в дообучение не отдавать.

## 9. Что не удалось проверить

- Работает ли PyTgCalls на **личных** звонках с приёмом и отправкой звука в 2026 (примеры — для групп; на PyPI заявлено).
- Качество кыргызского у Gemini на голосовых и Gemini TTS на кыргызском.
- Точные лимиты бесплатного уровня Gemini Live.
- Ставка исходящих звонков WhatsApp для КР и цена LiveKit-коннектора.
- Какой путь к лимиту 2000 действует сейчас; можно ли пройти верификацию бизнеса в КР.
