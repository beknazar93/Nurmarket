## 4. Предлагаемый контракт (подтвердите или поправьте)

Публичный блок в дизайне витрины:

```json
"telegram": { "enabled": true, "url": "https://t.me/<бот>", "product_url_template": "https://t.me/<бот>?start=p_{id}",
              "placement": ["cart", "product", "floating"] }
```

Заказ с витрины:

```json
POST /api/public/companies/{slug}/orders/    Idempotency-Key: <uuid>
{ "customer": {"name": "...", "phone": "+996..."}, "delivery": {...},
  "items": [{"product": "<id>", "variant": "<id|null>", "qty": 1}],
  "source": "showcase", "source_detail": "site_cart", "cart_token": "<token|null>" }
→ 201 { "id": "...", "number": "...", "total": "..." }   // повтор с тем же ключом → 200 с тем же заказом
```

Перенос корзины: `POST /api/public/companies/{slug}/cart-link/ {items:[…]}` → `{ "token": "<до 55 символов>" }`.

Если у вас уже есть другие имена полей — присылайте, мы подстроим кассу под ваши.

## 7. Другие вопросы из аудита кассы 01.11.2026 (не про витрину, но ждём ответа)

5. Дробное количество в приходе (весовые товары) — когда сервер начнёт принимать, сейчас принимает только целое.
6. Архив товара (`product_archive`) — когда появится в capabilities.
7. Возврат долгового чека после частичной оплаты (чек 001968 на 3 сом, оплаты по 1 + 1): сервер записывает выдачу 1, касса выдаёт 2 (по долгу). Какая цифра верна и как сервер считает выдачу?
