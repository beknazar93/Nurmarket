# Рекламный ролик NurCRM Mobile — сценарий и тексты для таргета (26.11.2026)

Ролики: `nurcrm-mobile-reklama-ru.mp4`, `nurcrm-mobile-reklama-ky.mp4` (9:16, 1080×1920, 30 к/с, H.264 + AAC, 32,4 с, ~3 МБ). Обложки: `…-ru-cover.jpg`, `…-ky-cover.jpg`.
Версия приложения — 1.18.23. Экраны в ролике — **макеты в стиле приложения на вымышленных данных** (товары, цены, имена придуманы; реальных чеков, клиентов, телефонов, логинов нет). Музыка — своя, синтезирована кодом (`src/music.py`), без речи. Шрифт Montserrat — свободная лицензия OFL (та же, что в приложении).

## 3. Как менять тексты, цену, срок

Все надписи, цена (`vars.price`), срок (`vars.trial`), адрес (`vars.url`) и название тарифа (`plan`) — в `src/texts.json`. Макеты экранов при этом не трогаются:

```
cd "docs\Реклама\src"
python build.py --texts-only            # оба ролика заново (~2,5 мин)
python build.py --texts-only --lang ky  # один язык
python build.py --texts-only --frames   # только кадры-превью (папка frames_preview), без видео
```
Сцену можно убрать, удалив её из списка `scenes`. Если менять названия кнопок на самих экранах — `src/screens.py`, затем `python screens.py`. Нужны Python с Pillow, Chrome (макеты), ffmpeg в `C:\Tools\ffmpeg`.

**Что проверить в кыргызском тексте (не уверены в оборотах):** «Касса — телефондо» (не «Касса — телефондо турат»?); «Бааны билүү», «Кабыл алуу», «Чейин 10 · 50 · 100» взяты из приложения, но «Чейин 10» в рекламе звучит неидеально; «Накладнойдун сүрөтү» (не «накладной сүрөтү»?); «Акылдуу камера», «Таанылды: 4 позиция» на экране; «эскертме жөнөт» (напомнить); «Автозапчастар» (не «автозапчасттар»?); «жүктөп ал» (на «ты») или «жүктөп алыңыз» (на «вы») — выбрать один стиль; «акысыз» против «бекер» для «бесплатно». Слова «кампа» (склад) и «киреше» (приход) — как в приложении.

## 6. Аудитория и настройка таргета

- **Кто:** владельцы и продавцы базаров и контейнеров («Дордой», «Мадина», «Ош базары» — как интересы/площадки, не как упоминание в ролике), мини-магазины у дома, павильоны, автозапчасти (рынок и СТО-магазины), малые оптовики. Второй слой: мастера-розничники, которым нужна простая касса без ПК.
- **География:** Бишкек и Бишкекский район, Ош, Кант, Токмок, Джалал-Абад, Каракол, Балыкчы, Нарын; затем вся республика. Языки: русский и кыргызский (два набора объявлений).
- **Возраст:** 22–55, основной пик 28–45; пол — любой (на рынках много женщин-продавцов).
- **Интересы/поведение:** малый бизнес, владельцы страниц бизнеса, интернет-торговля, оптовая торговля, автозапчасти, мобильные платежи (Мбанк, O!Деньги, ELQR) как платёжные привычки, Android-устройства (ролик про Android-приложение — исключить iPhone).
- **Цель кампании:** «Трафик» на nurcrm.kg или «Переходы по ссылке/установки», затем ретаргетинг по просмотру ролика (≥50 % ролика). Кнопка: «Подробнее» или «Скачать». Тест A/B: заголовок 1 против 3, ролик ru против ky по городам.
- **Бюджет теста:** по 5–10 долл. в сутки на набор, 3–5 суток, затем отключить слабые.

## 7. Что проверить перед запуском

1. **Ссылка скачивания.** `nurcrm.kg` открывается (проверено 26.11, HTTP 200), но на странице нет подтверждённой кнопки «скачать приложение». Установка сейчас — APK из `github.com/beknazar93/Nurmarket-Mobile` (репозиторий публичный, тег `mobile-X.Y.Z`). Магазинов приложений нет — ссылок на них в ролике нет, не придумывать. Решить: ведём на сайт с кнопкой или на страницу выпусков; в объявлении указать «для Android».
2. **Тариф и цена.** По решению владельца в ролике «Мини — 500 сом/мес» и «14 дней бесплатно»; сервер (`public/tariffs`) отдаёт mini = 500 сом, `trial_days` = 14 (проверено 26.11). Лимиты плана (1 сотрудник, 1 телефон) в ролике нет; в тексте объявления тоже не писать. Перед запуском ещё раз сверить цену и срок — они зашиты в `texts.json`.
3. **Умная камера** (сцена 3) работает при ИИ-ключе компании: убедиться, что у клиента «Мини» ИИ доступен; иначе убрать сцену из `scenes`.
4. **Торг «До 10/50/100»** — часть Простого режима (план «Мини» или переключатель «Простой режим (для базара)»); OEM-поиск — только у магазинов сферы «Автозапчасти» и при заполненных каталожных номерах товаров. Не обещать в объявлении «для любого магазина».
5. **Юридически (КР):** реклама без ложных обещаний, без «№1/лучший/единственный», без сравнения с конкурентами; указать, что экраны — иллюстрация (демо-данные); рекламодатель и контакт — по требованиям площадки (Meta/TikTok); для платных тарифов указать условия после пробного периода (сумма, продление) на странице скачивания, так как в ролике их нет. Для выделения «14 дней бесплатно» нужна страница с условиями.
6. **Права.** Музыка синтезирована кодом (своя, чужих материалов нет). Шрифт Montserrat — OFL (коммерческое использование разрешено). Логотип NurCRM — свой. Демо-данные вымышлены, номера и имена не настоящие.
7. **Кыргызский текст** — отдать носителю (раздел 5), правки внести в `texts.json` и пересобрать `--texts-only --lang ky`.
8. **Платформы:** загружать 1080×1920 mp4; в Reels/TikTok основной текст ролика лежит между y=150 и y=1670; превью подобрать из `…-cover.jpg`. Проверить звук: музыка тихая (средний уровень −24 дБ), без речи — без субтитров видео понятно по вшитому тексту.
