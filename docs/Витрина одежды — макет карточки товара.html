Макет: одежда на витрине

Фильтры по размеру и цвету, карточки с кружками цветов и «от … сом», окно товара с выбором цвета и размера, корзина с вариантом. Нажмите на товар. Поля API — в заметках внизу (ТЗ 21.10, часть 31).

Для фронтенда NurCRM — откуда данные

  • Список: GET public/companies/{slug}/showcase/?size=46&color=Белый — у товара has_variants, price_range (уже есть), colors[{name,hex}], sizes_in_stock[] (нужно). Фильтры: showcase/facets/.
  • Карточка: GET …/showcase/{id}/ → variants[{id,size,color,color_hex,sort_order,in_stock,low_stock,available,price,final_price,old_price,discount_percent}] (часть полей уже есть), colors[{name,hex,images[]}], sizes[], size_chart.
  • Размер, которого нет в выбранном цвете, — серый и зачёркнутый; его можно выбрать только для «Сообщить о поступлении» (POST …/showcase/{id}/notify/).
  • «В корзину» неактивна, пока не выбраны размер и цвет. Ключ строки корзины — product + variant.
  • «Оформить» — POST public/companies/{slug}/orders/ с items[{product, variant, qty}] и Idempotency-Key; ошибки variant_required, variant_out_of_stock (+ available). WhatsApp — только после создания заказа, с его номером.
  • Ссылка на вариант: ?variant=<uuid> открывает карточку с выбранным размером и цветом.
