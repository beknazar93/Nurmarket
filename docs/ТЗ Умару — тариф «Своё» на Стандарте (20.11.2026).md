# ТЗ Умару — тариф «Своё» (конструктор пакетов) должен работать и на «Стандарте» (20.11.2026)

Замечание владельца: «и в стандарте тоже можешь!». Сейчас на компании с тарифом «Стандарт» окно «Тариф «Своё»» открывается, но сервер отвечает на `POST api/users/company/tariff/quote/` кодом **409 `plan_not_allowed`** — и собрать набор нельзя. Касса по имени тарифа ничего не запрещает: решает только сервер. (Не отправлено, это черновик для Умара.)

## Что нужно
1. **Разрешить** `POST users/company/tariff/quote/` и `POST users/company/tariff/custom/` (заявка, Idempotency-Key как сейчас) для тарифов **start** и **standard** (и custom). Для остальных (например, mini) оставить 409, но с понятным текстом в `detail` на языке запроса (касса его покажет как есть).
2. **Что входит в «Стандарт»** — по `included_in` в `GET public/tariffs/` (уже отдаётся: у пакета список планов, куда он входит бесплатно). Для компании на «Стандарте» такие пакеты **вычитать**: ни абонплаты, ни подключения за них не брать; доплата только за пакеты, которых в «Стандарте» нет.
3. **Формат ответа quote** (старые поля оставить, чтобы старые кассы не сломались; новые — добавить):
```json
{
  "base_plan": "standard",
  "base": "3600.00",
  "included": ["ai", "clients", "scales"],
  "extra": [{"code": "salary", "monthly": "400.00", "once": "1500.00"}],
  "packs": [{"code": "salary", "monthly": "400.00", "once": "1500.00", "already_active": false}],
  "total_month": "4000.00",
  "total_once": "1500.00",
  "monthly": "400.00", "once": "1500.00",
  "standard_cheaper": false, "standard_price": "3600.00"
}
```
`standard_cheaper` на «Стандарте» всегда false. `included[]` — коды пакетов из запроса, что уже входят в тариф компании (в сумму не входят).

## Как касса ведёт себя сейчас и после ответа
- **Сейчас (ничего не менялось на сервере):** конструктор открывается; на 409 показывает «Конструктор «Своё» для вашего тарифа пока недоступен.» (плюс текст сервера, если он есть в `detail`), блокирует галочки и даёт кнопку «Написать менеджеру» (WhatsApp +996 221 068 796 с готовым текстом). Раньше писала жёстко «строится поверх «Старта»» — убрано.
- **После:** касса не меняется. Пакеты из `included_in` текущего тарифа помечаются «Входит в ваш тариф» (отмечены, не выбираются, в расчёт не отправляются), «Основа» в итоге берётся из ответа сервера, цены считает сервер (касса не считает).
- Нужен от Умара: ответ «да/нет» по пункту 1 и срок; формат п. 3 — если делается иначе, пришлите образец ответа.
