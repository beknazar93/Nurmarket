## Аудит живой программы владельца (18.10.2026, главная сессия, навык frontend-design)
Снимки: <scratchpad b41bdf8e…>\owner\tour_*.png (Склад, Продажи, Долги, Финансы, Прибыль и деньги, Клиенты, Зарплата, Настройки, Сводка).
Оценка: вид 5/10, удобство 6/10. Правила для ВСЕХ этапов О3+ (из аудита):
1. Кнопки: одна главная (жёлтая BrushPrimaryAction) на экран, остальные — обводка (modal-secondary); серых залитых и синих
   («Отправить товары →» в Настройках/Весы) нет; без «→» в тексте кнопок.
2. «Выбрано» (период, фильтр, вкладка, сегмент) — везде одинаково: тёмно-синяя заливка, белый текст (как modal-seg).
3. Суммы НИКОГДА не обрезаются «…» (Склад: «20 943 555 …», Продажи: «1 311,00 с», «Оплачено бону…») — плитки
   переносят подпись, число уменьшается/плитки в 2 ряда, без TextTrimming у денег.
4. Цвет со смыслом: жёлтый текст на светлом не использовать (контраст ~1,6:1); красный — только долг/просрочка/убыток
   (не «Возвраты 0,00», не «Скидки»); остатки — цветом только «мало/нет», норма нейтральная.
5. Склад: 6 значков без подписей в строке → основные 2 действия видимы с подписью/подсказкой, остальное в «⋯»;
   «Удалить» не рядом с частыми действиями; пагинация «1 из 7» — по возможности прокрутка (если не меняет загрузку).
6. Зарплата: в строках нет ИМЕНИ сотрудника (проверить колонку/привязку) — имя первой колонкой.
7. Клиенты: форма «Новый клиент» постоянно сверху → кнопка «+ Клиент» и окно ModalShell; подсказка «Нажмите на строку…»
   налезает на последнюю строку (ошибка вёрстки).
8. Финансы ≈ Продажи (те же показатели и список) — не дублировать вид; решение о слиянии — у владельца.
9. Меню: без ЗАГЛАВНЫХ подписей групп; плашка «Прокат» не в меню (→ «Требует внимания»); заголовок раздела не дублировать.
10. Доступность: у кнопок меню/иконок нет имени для UIA («Avalonia.Controls.Grid») — AutomationProperties.Name = подпись.
Сохранить: Долги (итог одной строкой, возраст долга чипами, WhatsApp), пояснения простыми словами, тёмная тема, Ctrl+K.
