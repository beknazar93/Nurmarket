NurCRM Kassa для macOS — ТЕСТОВАЯ сборка
===========================================

Это тот же код, что и касса для Windows и Linux, собранный под macOS 10.15 и новее.
Версия для Apple Silicon (M1/M2/M3/M4) — архив «-arm64», для Mac на Intel — архив «-x64».
.NET ставить не нужно — он внутри программы. На Mac эта сборка ещё НЕ проверялась.

Программа не подписана Apple (нет платного аккаунта разработчика), поэтому macOS при первом запуске скажет
«невозможно проверить разработчика» или «программа повреждена». Это нормально, обойти можно так:

Способ 1 (проще всего)
----------------------
1. Распакуйте архив (двойным щелчком), перетащите «NurCRM Kassa.app» в папку «Программы».
2. Откройте «Терминал» (Программы → Утилиты → Терминал) и вставьте две команды:
      xattr -cr "/Applications/NurCRM Kassa.app"
      codesign --force --deep -s - "/Applications/NurCRM Kassa.app"
   Первая снимает метку «скачано из интернета», вторая ставит локальную подпись без аккаунта (на Apple Silicon
   без неё программа не запустится вообще).
3. Запустите «NurCRM Kassa» из Launchpad или из папки «Программы».

Способ 2 (без Терминала — только для Mac на Intel)
-------------------------------------------------
Правый щелчок по «NurCRM Kassa.app» → «Открыть» → в окне предупреждения снова «Открыть». Дальше запускается
обычным двойным щелчком. Если macOS всё равно не пускает: «Системные настройки → Конфиденциальность и безопасность»
→ внизу кнопка «Всё равно открыть».

Программа владельца
-------------------
Тот же файл с ключом --owner. Запуск из Терминала:
      open -n -a "NurCRM Kassa" --args --owner
или двойным щелчком по «nurmarket-owner.command» из архива (один раз: правый щелчок → «Открыть»).

Где лежат данные
----------------
   ~/Library/Application Support/NurMarketKassa            (программа владельца — NurMarketOwner)
   Журнал:  ~/Library/Application Support/NurMarketKassa/Logs/nurmarket-kassa.log

Горячие клавиши: везде, где в кассе написано Ctrl, на Mac работает Cmd (⌘); Ctrl тоже работает.

Печать чеков
------------
Windows-очередей и LPT на Mac нет. В «Настройки → Печать → Порт принтера» укажите:
   192.168.1.50 или TCP:192.168.1.50:9100    сетевой чековый принтер (порт 9100 по умолчанию);
   CUPS:ИмяОчереди                           принтер, добавленный в «Принтеры и сканеры» (печать «сырых» данных);
   /dev/cu.usbserial-XXXX                    принтер через USB-переходник COM (список портов — в окне настроек).

Что пока не работает на Mac
---------------------------
- Встроенный сайт NurCRM внутри программы (есть кнопка «Открыть в браузере»).
- Автообновление (обновления скачиваются вручную).
- Графический чек (есть текстовый), принтеры ценников через драйвер Windows.
- Голосовой ввод (звуки кассы работают через afplay).
- Камера/микрофон для ИИ-помощника не проверялись.

О найденных ошибках сообщайте в поддержку NurCRM.
