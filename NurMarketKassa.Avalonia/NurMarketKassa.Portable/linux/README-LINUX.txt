NurMarket Kassa для Linux — ТЕСТОВАЯ сборка
===========================================

Это тот же код, что и касса для Windows, собранный под Linux (x64).
На Linux эта сборка ещё НЕ проверялась — это первая версия для тестирования.

Требования: Ubuntu 22.04 / 24.04 (или похожий Linux x64) с рабочим столом.
.NET ставить не нужно — он внутри архива.

Установка
---------
1. Распаковать архив, например в домашнюю папку:
      mkdir -p ~/nurmarket && tar -xzf nurmarket-kassa-linux-x64-*.tar.gz -C ~/nurmarket
2. Если чего-то не хватает в системе (обычно уже есть):
      sudo apt install -y libicu-dev libfontconfig1 libx11-6 libice6 libsm6
3. Запуск кассы:
      ~/nurmarket/NurMarketKassa.Avalonia
   Запуск программы владельца:
      ~/nurmarket/nurmarket-owner.sh

Что пока не работает на Linux
-----------------------------
- Встроенный сайт NurCRM внутри программы (кнопка «Открыть в браузере» работает).
- Автообновление (обновления пока скачиваются вручную с этой страницы).
- Голосовое управление.
- Принтеры чеков, подключённые через драйвер Windows и WinUSB. Сетевые принтеры
  (TCP 9100) и COM-порты (/dev/ttyUSB0, /dev/ttyS0) — проверяются.

О найденных ошибках сообщайте в поддержку NurMarket.
