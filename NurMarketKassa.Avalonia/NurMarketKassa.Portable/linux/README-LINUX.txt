NurCRM Kassa для Linux — ТЕСТОВАЯ сборка
===========================================

Это тот же код, что и касса для Windows, собранный под Linux (x64).
На живом Linux эта сборка проверялась мало — это версия для тестирования.

Требования: Ubuntu 22.04 / 24.04 (или похожий Linux x64) с рабочим столом.
.NET ставить не нужно — он внутри архива.

Установка
---------
1. Распаковать архив, например в домашнюю папку:
      mkdir -p ~/nurmarket && tar -xzf nurmarket-kassa-linux-x64-*.tar.gz -C ~/nurmarket
2. Если чего-то не хватает в системе (обычно уже есть):
      sudo apt install -y libicu-dev libfontconfig1 libx11-6 libice6 libsm6 libgtk-3-0 xdg-utils
   (libgtk-3-0 нужна для окон «Открыть / Сохранить файл», xdg-utils — чтобы открывались ссылки и папки.)
3. Ярлыки в меню приложений (по желанию):
      ~/nurmarket/install-desktop.sh
   Появятся «NurCRM Касса» и «NurCRM Владелец». Убрать: install-desktop.sh --remove
4. Запуск кассы без ярлыка:
      ~/nurmarket/NurMarketKassa.Avalonia
   Запуск программы владельца:
      ~/nurmarket/nurmarket-owner.sh
   Если пишет «Permission denied» — файлы потеряли право запуска (распакованы не tar):
      chmod +x ~/nurmarket/NurMarketKassa.Avalonia ~/nurmarket/*.sh

Экран и масштаб
---------------
Касса сама подгоняет окна под экран (1366×768, 1024×600 и т.п.). Если масштаб системы определился неверно
(на Wayland приложение работает через XWayland), задайте его вручную перед запуском:
      AVALONIA_GLOBAL_SCALE_FACTOR=1.25 ~/nurmarket/NurMarketKassa.Avalonia
Режим слабого устройства (Настройки → Экран) на Linux включает программный рендер.

Печать чеков
------------
Очередей Windows и LPT на Linux нет. В «Настройки → Печать → Порт принтера» укажите:
   /dev/usb/lp0                  USB-принтер (ядро создаёт файл при подключении);
   192.168.1.50 или TCP:192.168.1.50:9100   сетевой принтер (порт 9100 по умолчанию);
   CUPS:ИмяОчереди               принтер, добавленный в CUPS (печать «сырых» данных, lp -o raw);
   /dev/ttyUSB0                  принтер/весы через USB-переходник COM.
Список найденных устройств показывает окно настроек. Если «нет прав на устройство» — добавьте себя в группы
и перезайдите в систему:
      sudo usermod -aG lp,dialout $USER
Штрихкод-сканер, который работает как клавиатура, подключать не нужно — он работает сразу.
Сканер через COM — порт /dev/ttyACM0 или /dev/ttyUSB0 (так же, как COM для весов).

Что пока не работает на Linux
-----------------------------
- Встроенный сайт NurCRM внутри программы (кнопка «Открыть в браузере» работает).
- Автообновление (обновления пока скачиваются вручную с этой страницы).
- Голосовое управление.
- Графический чек (печатается текстом), принтеры ценников и этикеток через драйвер Windows.
- Принтеры чеков, подключённые только через драйвер Windows и WinUSB.

О найденных ошибках сообщайте в поддержку NurCRM.
