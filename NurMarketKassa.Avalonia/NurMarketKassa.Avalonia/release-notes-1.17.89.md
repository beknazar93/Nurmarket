## v1.17.89 (тестовая версия)

Сфера «Автозапчасти» после живой проверки на тестовой компании: аналоги на сервере, поиск «бренд + номер», исправление окна оплаты, «Заказы под клиента» в меню, окно «Подробнее» на низком экране. Всё из 1.17.88 сохраняется.

Файлы для установки:

- `NurMarketKassa-win-Setup.exe` — касса (при первом запуске спросит, ставить ли программу владельца).
- Linux — `nurmarket-kassa-linux-x64-1.17.89.tar.gz`; Android — `nurmarket-kassa-android-1.17.89.apk`.

Тестовая версия: обновление видят только кассы с кодом тестировщика (Настройки → Обновления). Обновление не меняет ваши настройки.
