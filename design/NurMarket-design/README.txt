NurMarket — дизайн (локальная копия холста)

index.html   — оглавление: все экраны по разделам, с превью и поиском. Откройте двойным щелчком.
screens/     — каждый экран отдельным статичным HTML-файлом (открывается без интернета;
               шрифт Montserrat подгружается из Google Fonts при наличии сети).
source/      — исходники холста без изменений: *.dc.html, canvas.json, support.js (рантайм),
               ds/nurcrm/tokens.json. Нужны для повторного импорта/редактирования.
               Для просмотра исходников через рантайм нужен локальный веб-сервер
               (например: python -m http.server в папке source), т.к. экраны подключают друг друга.

действий у выбранной строки. Внедрены точечно: окно оплаты, меню ☰ плитками, Сводка владельца. Не сверяйте живую кассу с этими картинками один к одному.
