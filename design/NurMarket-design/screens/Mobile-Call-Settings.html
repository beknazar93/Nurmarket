Г6 · «Помощник» (/ai/settings): режим голосового управления

Три режима радиокнопками (карточка ≥ 72 dp, заголовок + объяснение одной-двумя строками), отметка «по умолчанию». Для сотрудника — режим, который задал владелец, показан замком; сотрудник может выбрать только строже (для себя). Голосом режим не меняется — только здесь. Внизу ссылка «Действия ИИ ›» и «Голосовой звонок доступен всем, у кого есть ключ ИИ магазина».

Состояния

  • owner — владелец, выбран «Выполнять по просьбе» (по умолчанию).
  • watch — выбран «Только смотреть»: объяснение, что ИИ ответит на просьбу об действии.
  • ask — «Спрашивать перед деньгами»: список денежных действий, перед которыми будет карточка «Сделать».
  • employee — кассир: плашка «Владелец задал для всех на этом телефоне: Спрашивать перед деньгами»; «Выполнять по просьбе» недоступен (мягче), «Только смотреть» можно выбрать для себя.
