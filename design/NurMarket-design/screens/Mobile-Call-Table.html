Г3 · Нижняя панель таблицы (DraggableScrollableSheet, CallTable)

Три высоты: свёрнута 96 dp (ручка, название, итог), половина (по умолчанию), весь экран. Новая таблица заменяет прежнюю, прежние — «‹ 2/4 ›»; «Закрепить» — новая открывается вкладкой рядом. Первая колонка закреплена при горизонтальной прокрутке, заголовок — при вертикальной, «Итого» прилипает снизу. Нажатие на заголовок — сортировка, на строку — открыть объект (звонок сворачивается в плашку). Цифры — tabularFigures, выравнивание вправо; отрицательные — красным (T.danger), не только минусом.

Состояния

  • half — звонок развёрнут (круг 96 dp, 2 строки субтитров, ряд кнопок над панелью), панель на половину: «Продажи по дням», 20 из 26 строк.
  • min — панель свёрнута до 96 dp: «Продажи по дням · Итого 312 400 сом · 26 строк», ✕. Весь экран звонка виден.
  • full — панель на весь экран, сверху ручка и «⌄» (свернуть); ряд «Микрофон / Громкая / Завершить» скрыт — звонок в заголовке панели компактно (таймер + «Завершить» 48 dp).
  • sorted — голосом «отсортируй по сумме»: колонка «Сумма» выделена, стрелка ↓, чип «по сумме ↓» в строке действий.
  • pinned — вкладки: «📌 Должники» и «Продажи по дням» (активная); закреплённая не заменяется новой.
  • more — после «покажи ещё»: 40 из 500, кнопка «Показать ещё 20» остаётся, подпись «ещё 460».
  • empty — по фильтру ничего нет: «Пока пусто», «По запросу «долг больше 10 000» — ничего», «Снять фильтр».
  • wide — 8 колонок (зарплата): горизонтальная прокрутка, первая колонка закреплена с тенью, итоги по числовым колонкам.
  • card — один объект (товар) — та же панель в виде «поле — значение».
  • over — панель поверх раздела «Склад» и мини-плашки (звонок свёрнут).
  • big-font — тот же half, но смотреть с переключателем «Шрифт 1.3»: колонки переносятся, ширина по содержимому, высота строки растёт до 52.
