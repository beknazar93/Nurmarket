Г5 · «Действия ИИ» (/ai/log, Профиль)

Список по дням: время, значок группы (навигация / корзина / деньги / товар / задачи / зарплата), сказанная фраза серым курсивом, итог жирным, справа «Отменить» (40 dp в строке, хитбокс 48) либо серое «нельзя отменить» / «отменено 14:07». Фильтры-чипы: Все · Только деньги · Отменённые. Сотрудник видит свои записи, владелец и администратор — все записи телефона. Внизу — откуда данные: телефон, до 2000 записей, без ключей, звука и телефонов клиентов.

Состояния

  • owner — все записи за «Сегодня» и «Вчера», смешанные группы, у денег значок на жёлтой подложке.
  • money — фильтр «Только деньги»: оплата, приход, выплата, долг.
  • employee — кассир: плашка «Видны только ваши действия», записей меньше, «Отменить» только у своих отменяемых.
  • undone — после нажатия «Отменить»: тост «Отменено: возврат чека 1043…», запись помечена «отменено 14:07», ниже — новая запись об отмене.
  • empty — пусто: «ИИ ещё ничего не делал на этом телефоне», подсказка про звонок.
