По ТЗ «Склад — массовое добавление — скан 3 колонки, Excel, CSV». В каждом макете сверху панель просмотра: тема (светлая/тёмная), окно 1296×879 / 1024×600, «ky — длинные подписи» (проверка переносов), «ключи Tr.T» (имена строк для Sonnet) и состояния экрана. Параметры через адрес: ?theme=dark&size=1024&ky=1&keys=1#состояние. Общие стили — BulkAdd-shared.css (токены кассы), общий скрипт — BulkAdd-shared.js (значки MarketplaceIcons, панель).

Д1–Д5BulkAdd-Scan — Массовое сканированиеТри колонки «Есть на складе / Есть в базе CRM / Неизвестный штрихкод». Пусто, черновик, найдено (+1, база CRM, неизвестный с подсказками, «проверяю…», «не проверено»), много строк, ошибки → подтверждение → итог, «Провожу…» → «в фоне» → тост. Д6BulkAdd-Import1 — шаг 1: файлПеретаскивание, выбор, шаблон, вставка из буфера; Excel — лист и строка заголовков; CSV — кодировка и разделитель; .xls / > 20 МБ / пустой / кракозябры; скан в режиме импорта. Д7BulkAdd-Import2 — шаг 2: столбцыНаше поле → столбец файла → пример; подсказка для процента; наценка по умолчанию, дубли; всё узнано само / не хватает обязательного / как в прошлый раз. Д8BulkAdd-Import3 — шаг 3: проверкаПлитки «Все / Приход / Новые / Ошибки», таблица с подсветкой ячеек, «Скачать строки с ошибками», «Загрузить 14 800»; «Проверяю 6 000 из 15 000»; подтверждение цены продажи. Д9BulkAdd-Result — загрузка и итог«Загрузка в фоне: 3 400 из 14 800 · можно закрыть окно», ждёт связь, готово, частично («нужна проверка» в «Приходах в фоне»).
