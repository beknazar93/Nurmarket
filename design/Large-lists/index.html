01 · Модалка «Позиции прихода»Шаблон целиком: сворачиваемые реквизиты, сводка, поиск Ctrl+F, чипы, сортировка, группы, виртуализация, карточки, обзор, выделение и групповые действия, правка на месте, состояния (загрузка / пусто / нет совпадений / ошибка / долгая операция), полный экран. 02 · Печать, PDF, Excel/CSVРазбивка на страницы с повтором шапки, «стр. 3 из 14», перенос сумм, итог и подписи на последней; «Только итоги» (1 страница), «Только расхождения», «Без пустых колонок»; A4 / альбомная / лента 80 мм. 03 · Мобилка и планшетРевизия на 4 000 позиций: поиск и чипы сверху, ленивая подгрузка по 40, sticky-группы, закреплённые итоги снизу, «К началу», лист «Обзор», скелетон с прогрессом.
Пять правил. 1) Модалка не выше 88 % окна, растёт только список; шапка колонок, сводка и кнопки закреплены. 2) От 200 строк — виртуализация, поиск с дебаунсом 200 мс, открытие ≤ 300 мс на 500 строках. 3) От 50 строк — поиск (ё=е, раскладка, транслит), чипы с количеством, «Показано N из M», «Требуют внимания» кликабельно. 4) Три режима: Таблица / Карточки / Обзор; 1024×600 прячет колонки по приоритету, 360 dp — только карточки и обзор, кнопки в «Ещё». 5) Печать и экспорт без потолка: страницы с повтором шапки и итогом на последней, «Только итоги» всегда 1 страница, Excel/CSV в фоне с прогрессом и отменой.
